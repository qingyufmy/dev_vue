AI 交易实验室 · 使用指南

v2.0.2 | 2026年6月

本系统通过 AI 自动分析黄金市场行情，生成交易信号并可一键执行到 MT5 账户。

3分钟上手

1

登录系统

打开浏览器访问系统地址，输入账号密码登录。

⚠️ AI交易实验室为 Pro 会员 专属功能。免费用户会看到升级提示。
2

连接 MT5 Bridge

Bridge 是连接 MT5 交易终端和服务器的桥梁程序。

  • 点击右上角「桥接状态」徽章
  • 点击「下载桥接软件」
  • 运行 AURUM_Bridge.exe
  • 输入 MT5 账号信息，点击「登录并连接」

连接成功后状态栏显示 ✅ MT5桥接-已连接

3

开启自动推理

点击顶部「自动推理」徽章，开启自动推理功能。

开启后系统会每隔 5 分钟自动分析市场，生成交易信号。

开启自动推理

💡 新手只需 3 步即可开始使用系统

你只需要做一件事：点击顶部「自动推理」状态栏，开启自动推理。

开启后，系统会：

  • 每隔 5 分钟自动分析市场
  • 生成交易信号（做多/做空/观望）
  • 信号显示在概览页的「AI 信号」卡片中

查看信号

信号卡片包含以下信息：

项目说明
方向BUY 做多 / SELL 做空 / HOLD 观望
置信度AI 的把握程度（越高越可靠）
止损/止盈建议的价格位置
有效期过期后不可执行

执行信号

  1. 点击信号卡片查看详情
  2. 确认止损止盈价格
  3. 点击「执行信号」
  4. 确认弹窗中检查参数
  5. 点击「确认执行」
⚠️ HOLD（观望）信号不可执行，系统会自动跳过。

手动交易

  1. 选择品种
  2. 选择方向：买入（做多）/ 卖出（做空）
  3. 输入手数
  4. 点击「发送订单」→ 确认

平仓操作

在持仓列表中，点击对应持仓的「平仓」按钮即可关闭。

模型配置

进入「配置」→「模型设置」，可以配置 AI 分析所使用的模型。

参数说明推荐值
API 服务商DeepSeek / GPT / Kimi / Qwen 等DeepSeek
API Key对应服务商的密钥-
模型名称如 deepseek-chatdeepseek-chat
Temperature输出随机性 0-10.3-0.7
Max Tokens最大输出长度2000
💡 管理员开启模型共享后，无需配置 API Key 也能使用。

系统提示词

在「配置」→「模型设置」中，可以修改系统提示词来定制 AI 的分析行为。

提示词中可使用时间框架标签：

标签用途示例
{{MTF:M5:100}}手动推理时获取 M5 周期 100 根K线放提示词开头
{{ATF:H1:80}}自动推理时获取 H1 周期 80 根K线放提示词开头
{{CTF:M5:50}}智能平仓时获取数据放提示词开头

自动推理参数

进入「配置」→「自动推理」：

参数说明默认值
分析品种交易品种XAUUSD
分析间隔多久分析一次5 分钟
自动执行信号是否自动下单关闭

风控参数

在「配置」→「模型设置」中调整：

参数说明推荐值
风险级别low/medium/highmedium
最大手数单笔最大交易量0.05
止盈档位选择 TP1/TP2/TP3TP1

手动推理

  1. 进入「AI推理」页面
  2. 选择品种和分析周期（M5/M15/H1/H4）
  3. 点击「生成信号」
  4. 等待 10-30 秒

历史记录

交易历史：显示所有已完成的交易，支持按时间、方向、盈亏筛选。

盈亏曲线：每日盈亏柱状图、累计盈亏折线、回撤曲线、胜率/盈亏比/最大回撤。

信号历史：显示所有 AI 生成的信号，支持按方向、时间框架筛选。

注意事项

  • Bridge 必须在运行 MT5 的电脑上运行
  • 市场休市时（周末），自动推理自动暂停
  • 所有交易操作都会记录审计日志
  • AI 分析仅供参考，交易风险自行承担
  • 一个账号只能连接一个 Bridge

常见问题

Q: Bridge 连接失败？
A: 确认 MT5 已登录 → 检查网络 → 确认 Pro 权限 → 检查防火墙

Q: 自动推理没运行？
A: 检查 Bridge 状态 → 检查市场是否休市 → 检查 API Key → 检查开关

Q: 信号没执行？
A: 检查自动执行开关 → 检查交易发送 → 检查保证金 → 检查是否过期

Q: Plus 用户能做什么？
A: 只能观摩，不能交易。升级 Pro 解锁全部功能。
