📖 使用手册 AI交易实验室完整功能说明

🚀 快速开始

第一步：下载并安装桥接软件

  1. 登录后进入 AI 交易实验室
  2. 点击右上角「桥接状态」徽章，或进入「配置」页面
  3. 点击「下载桥接软件」按钮
  4. 运行下载的 AURUM_Bridge.exe
  5. 输入服务器地址（默认已填好）和您的账号密码
  6. 勾选「记住密码」可自动填充
  7. 点击「登录并连接」

预期结果：桥接软件显示「MT5桥接-已连接」，网页右上角徽章变为绿色「MT5桥接-已连接」

第二步：确认 MT5 连接

  1. 确保 MT5 终端已登录并运行
  2. 桥接软件会自动检测并连接 MT5
  3. 连接成功后，页面行情区域会显示实时报价

预期结果：行情区域显示 bid/ask 价格，数字会实时跳动

第三步：选择品种

  1. 在行情区域左侧的品种选择器中输入或选择品种
  2. 支持搜索：输入 "XAU" 会过滤显示所有黄金相关品种
  3. 切换品种后，报价、K线图、持仓列表会同步更新

预期结果：品种名称显示在选择器中，报价和K线图更新为该品种数据

第四步：生成 AI 信号

  1. 进入「AI推理」页面
  2. 确认品种选择器中显示正确的品种
  3. 选择分析周期（M5/M15/H1/H4）
  4. 点击「生成信号」按钮
  5. 等待 AI 分析完成（通常 10-30 秒）

预期结果：显示分析进度条，完成后展示信号卡片（买入/卖出/持有），包含置信度、止损止盈价格

📊 概览页面

功能说明：显示实时行情、当前持仓、市场状态，支持快捷交易操作。

行情区域：

  • 左侧：品种选择器（支持搜索）
  • 中间：实时 bid/ask 报价，数字跳动表示数据更新
  • 右侧：市场状态（交易中/休市/检测中）、MT5 服务器时间

持仓列表：

  • 显示当前所有持仓：订单号、品种、方向、手数、开仓价、当前价、盈亏
  • 盈亏数字：绿色=盈利，红色=亏损
  • 平仓按钮：点击可快速平仓

快捷交易：

  • 输入手数（默认 0.01）
  • 点击「买入」或「卖出」按钮
  • 确认弹窗中检查参数后点击「确认发送」

预期结果：交易成功后持仓列表更新，审计日志记录操作

🤖 AI 推理

功能说明：使用 AI 模型分析市场数据，生成交易信号。

手动推理：

  1. 进入「AI推理」页面
  2. 选择品种（默认使用概览页面选择的品种）
  3. 选择分析周期：M5（5分钟）、M15（15分钟）、H1（1小时）、H4（4小时）
  4. 可选：修改系统提示词（高级用户）
  5. 点击「生成信号」按钮
  6. 等待进度条完成（显示当前阶段和预计时间）

预期结果：显示信号卡片，包含：

  • 方向：买入(🟢) / 卖出(🔴) / 持有(🟡)
  • 置信度：0-100%（越高越可靠）
  • 止损价格：建议的止损位
  • 止盈价格：TP1/TP2/TP3 三级止盈
  • 分析理由：AI 的分析逻辑

自动推理：

  1. 进入「配置」页面 → 自动推理标签
  2. 开启「自动推理」开关
  3. 设置分析间隔（默认 5 分钟）
  4. 确认「自动执行」开关状态：
    • 开启：AI 信号符合条件时自动下单
    • 关闭：仅生成信号，需手动确认执行
  5. 点击「保存配置」

预期结果：左上角徽章显示「自动推理运行中 · XAUUSD · 5分钟」

自动推理流程：

  • 系统每 5 分钟自动获取行情数据
  • 调用 AI 模型分析市场
  • 生成信号并保存到历史记录
  • 若开启自动执行且信号非 HOLD，自动下单
  • 市场休市时自动暂停，恢复交易后继续

信号执行：

  1. 在信号列表中点击要执行的信号
  2. 查看信号详情：方向、置信度、止损止盈
  3. 点击「执行信号」按钮
  4. 确认弹窗中检查参数
  5. 点击「确认执行」

预期结果：MT5 终端执行订单，信号标记为「已执行」

风控规则：HOLD 信号不可执行；信号过期不可执行；手数超过配置上限被拒绝

💹 交易页面

功能说明：手动交易、持仓管理、平仓操作。

手动下单：

  1. 选择品种
  2. 选择方向：买入(多) / 卖出(空)
  3. 输入手数（0.01-手数上限，由风控配置决定）
  4. 可选：设置止损价格、止盈价格
  5. 点击「发送订单」
  6. 确认弹窗中检查参数（预估入场价、保证金、滑点）
  7. 点击「确认发送」

预期结果：MT5 终端执行订单，持仓列表更新

风控检查：系统会自动检查手数上限、保证金充足性、价格滑点

持仓管理：

  • 持仓列表实时更新（通过 WebSocket 推送）
  • 每行显示：订单号、品种、方向、手数、开仓价、当前价、盈亏
  • 盈亏颜色：绿色=盈利，红色=亏损
  • 点击「平仓」按钮可快速平仓

预期结果：平仓后持仓列表更新，审计日志记录操作

📜 历史记录

功能说明：查看交易历史、盈亏曲线、统计分析。

交易历史：

  • 显示所有已完成的交易订单
  • 支持按时间范围、方向、盈亏筛选
  • 分页加载（每页 20 条）
  • 点击订单号可跳转到关联的 AI 信号

盈亏曲线：

  • 每日盈亏柱状图
  • 累计盈亏折线图
  • 回撤曲线
  • 统计指标：胜率、盈亏比、最大回撤

信号历史：

  • 显示所有 AI 生成的信号
  • 支持按方向、时间框架筛选
  • 点击信号可查看详情和执行状态

⚙️ 配置页面

功能说明：管理 AI 模型、API Key、自动推理参数。

模型设置（仅 Pro 用户可见）：

  • API 服务商：DeepSeek / GPT / Kimi / Qwen / 智谱 / 豆包 / Claude / Gemini
  • API Key：输入对应的 API 密钥
  • 模型名称：选择具体模型（如 deepseek-chat）
  • Temperature：控制输出随机性（0-1，推荐 0.3-0.7）
  • Max Tokens：最大输出 token 数（推荐 2000）
  • 风险级别：low / medium / high（影响仓位和止损计算）
  • 最大手数：单笔交易最大手数限制
  • 止盈档位：选择 TP1/TP2/TP3
  • 系统提示词：自定义 AI 分析的指令

预期结果：保存后立即生效，下次推理使用新配置

自动推理配置（仅管理员可编辑全局配置）：

  • 分析品种：默认 XAUUSD
  • 分析间隔：5 分钟（可调整）
  • 自动执行开关：开启后 AI 信号自动下单
  • 使用独立的 API Key 和模型设置

预期结果：保存后自动推理调度器使用新配置

⚠️ 重要注意事项

  • 桥接软件必须在运行 MT5 的电脑上运行，不能在服务器上运行
  • 自动推理开启后，系统会按设定间隔自动分析和执行，请确保风控参数设置合理
  • 市场休市时（周末、每日特定时段），自动推理会自动暂停
  • 所有交易操作都会记录审计日志，可在「审计」页面查看
  • AI 分析结果仅供参考，交易风险由您自行承担
  • 不要同时运行多个桥接实例，一个账号只能连接一个桥接
  • 定期检查 API Key 余额，避免因余额不足导致推理失败

🔧 常见问题

Q: 桥接连接失败怎么办？
A: ① 确认 MT5 已登录并运行 ② 检查网络连接 ③ 确认账号权限为 Pro ④ 检查防火墙是否阻止连接
Q: 自动推理没有运行？
A: ① 检查桥接状态是否为「已连接」 ② 检查市场是否休市 ③ 检查 API Key 是否配置正确 ④ 检查自动推理开关是否开启
Q: 信号没有自动执行？
A: ① 检查「自动执行」开关是否开启 ② 检查交易发送是否开启 ③ 检查保证金是否充足 ④ 检查信号是否过期（M5信号45秒过期）
Q: AI 分析失败？
A: ① 检查 API Key 是否有效 ② 检查 API 余额是否充足 ③ 检查网络连接 ④ 查看审计日志中的错误信息
Q: 持仓数据不更新？
A: ① 检查桥接状态 ② 检查交易发送是否开启 ③ 点击「刷新」按钮手动刷新 ④ 重启桥接软件
Q: Plus 用户能做什么？
A: Plus 用户处于观摩模式，只能查看管理员连接的 MT5 账户数据，不能交易、不能配置、不能下载桥接软件。如需完整功能，请升级 Pro。
Q: 如何切换深色/浅色模式？
A: 点击右上角的主题切换按钮（月亮/太阳图标）
