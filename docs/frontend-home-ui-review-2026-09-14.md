# 首页与公共运行状态审查

范围：2026-09-14 当前 localhost:4174 首页，桌面 1294×912 截图与源码；未验证其他页面全部流程、移动端或键盘交互。本轮不修改开关或交易状态。

1. 顶栏及导航：结构清楚。时区在顶栏、账户卡、图表重复；建议只保留图表的公共行情时间和 UTC 偏移，确认详情通过可点击说明查看。顶栏优先显示页面、当前交易账户和用户菜单；多在线账户时才显示切换下拉。
2. 运行状态：缺少自动分析、交易执行控制和市场开闭。现有“账户允许交易”仅为权限，不能代表自动交易已启用；“数据实时同步”代表连接状态，当前实际 K 线为空，表达过强。建议同一状态栏左侧放两项控制，右侧放连接摘要；市场开闭放在品种旁。市场状态只用开市/休市，无证据时显示待确认，不能从报价推进或权限推断。
3. 首页概览：标题、说明及账户卡占据较多首屏高度，桥接与权限标签重复。建议压缩成账户身份一行、资产指标一行；零盈亏用中性色；最新分析无结果时不保留巨大空卡。
4. 行情与异常：缓存读取和选源绑定造成无限加载，公共时区也丢失；优先修复。历史缓存可展示，过期报价不可标为实时。加载、无数据、断开和错误应区分；错误提供重试。当前禁用的全屏入口应实现或暂不展示。

控制语义复核：复用现有订阅 analysisEnabled、traderEnabled、tradeSendEnabled，不新增重复状态源。快捷操作必须明确当前账户及订阅；多个订阅不应被一个无范围开关暗中批量改变，可点击进入当前账户的简短列表。公共分析不允许普通用户关闭其他用户使用的公共任务。倒计时由服务端 nextRunAt 在前端计算，不新增秒级推送。关闭执行不自动平仓/撤单；对风险管理的实际影响在实施前核对执行服务。

可访问性：小型胶囊需保留足够点击面积与键盘焦点，文字表达状态而非仅用颜色；提示同时支持点击和键盘，不能只依赖悬浮。移动布局和对比度需在实施后实测。

实施优先级：公共缓存/时区独立读取 → 控制与真实状态接线 → 首屏压缩及响应式验证。无需重做侧栏、配色或引入新 UI 框架。

## 本轮实施与验收

复核一：公共缓存与采集连接解耦。复用现有管理员账户行情表，按标准品种、周期选择有最新缓存的授权管理员账户，分页固定从该份缓存读取；不把不同来源的单根 K 线拼接，不增加数据库表或逐秒 HTTP。公共校准读取管理员最近可信、当前归属与终端匹配的记录，不依赖在线行情选源。现有私有策略采集接口与执行权限不变。

复核二：公共读取前后复查管理员、账户归属与品种目录；缓存标识按标准品种、账户与实际品种生成，连接重建不再改变缓存标识。source_generation=1 表示本版缓存命名空间，真实账户缓存变化由 source_key 区分；公共实时转发复查当前采集 generation 并匹配缓存键，拒绝跨来源转发。API 与公共行情 worker 应配套更新。管理员缓存仍在现有账户行情表中，不声称已经迁移成独立无账户公共表。

UI 已增加两个订阅控制入口，按当前账户展示具体订阅；通过现有幂等键、If-Match 与 CSRF 保存，确认后才修改，账户切换丢弃旧响应。未配置时有策略管理入口；本轮未开启任何真实交易。倒计时读取 nextDueAt 并在本地每秒计算，设置每30秒刷新。前端删掉重复时区/权限/桥接标签、压缩账户身份和指标、零盈亏中性色、缩小空分析卡；时区确认详情改为图表底部可点击按钮。

## 2026-09-14 管理员桥接市场状态接线

本节取代前节市场状态未接线的结论。按用户确认，公共市场状态由当前选中的管理员桥接判定，普通用户共享后端结果；多个管理员交易账户继续沿用现有固定选源与故障切换，不新增配置。

规则复核：只读参考旧版 business-adapter.js 的 classifyQuoteMarket。MT4、MT5 共用桥接端分类：终端断开或证据缺失为 unknown；品种交易模式为0时 closed，1至3时 restricted；超过120秒未更新的报价，UTC周末为 closed，工作日为 stale；有效新报价且模式为4时 open。未来异常时间不能判为开市。前端只展示结果和检查是否过期，不自行计算周末或凭账户交易权限判断市场。

实现复核：现有 market.instrument 回复增加可选 market_state（state、reason、checked_at_utc_msc），桥接通过同一终端的只读报价查询分类。后端沿用选源状态JSON保存结果，公开品种接口增加可选 market_states，兼容旧桥接缺失字段。只接受当前授权管理员所选来源的结果；失效、来源不可用或超过45秒未确认时显示待确认。前端每15秒复用公共品种小响应刷新，不重拉历史K线。
