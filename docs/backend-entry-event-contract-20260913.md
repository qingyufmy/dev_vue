# 交易触发事件与使用记录

本方案细化已授权核心包 1 的事件语义，不改变策略方向、风险额度或启用状态。

## 合同与实施顺序

1. market 从冻结且时间可信的已收盘 K 线计算客观事件，先覆盖旧实现的两根收盘突破和收回确认。事件 ID 由源账户、品种、周期、事件类型、方向及原始发生时间组成；不包含分析任务 ID、滑动窗口下标、当前价格或持仓。追加行情不能把旧事件变成新事件。事件 ID 只标识一个客观事件，不证明它是策略允许的独立新机会。
2. inference 将分析时完整事件证据冻结入库，交易员只能引用同一份已冻结事件。缺少事件、能力不支持、时钟未知或不完整行情时保持不可用，禁止让模型自己生成去重键。
3. 使用账本按真实用户、账户、策略和事件隔离。账户锁与唯一键保障并发；占用随决策事务持久化，风险拒绝可解除尚未执行的占用，风险批准后保守视为已使用，不因超时、未知结果或挂单撤销而自动释放。分析 hold 不消耗事件。读取提示只帮助模型，最终事务校验才是去重权威。
4. 旧策略的 M15 新机会与 M5 新事件同时成立、加仓权限属于额外规则（15 分钟同向冷却在原文仅为建议，不升级为硬限制），不能用一个未使用的事件 ID 替代。账本及这些规则完成并验收前，不解除旧角色候选的事件阻断。

## 第一轮复核：需求与职责

market 只计算已存在的客观定义；inference 保存身份与使用记录；risk 保留批准权；execution 保留终端状态权威。不建立策略专属分支，不混入观察账户和执行账户，不用提示词提醒代替事务互斥。先有真实事件再接账本，避免记录模型任意字符串而得到虚假的去重保证。

## 第二轮复核：兼容与异常

沿用旧突破算法的 20 根参考窗口和最近 8 个确认候选，参考窗口排除两根触发 K 线。收回需要后续确认，失效事件保留身份但不作为有效触发；滑窗和新行情保持同一事件 ID，价格修订不产生新的重复使用机会。输入、输出和 UTC 时间有界验证，未收盘尾 K 不参与判断。无可信休市区间时跨缺口失败关闭。

增加可选行情证据不改旧表、不回填历史、不启用旧策略。新增账本需追加兼容迁移，现有数据原样保留；应验证重复投递、两个并发决策、风险拒绝、提交结果未知和跨账户隔离。未完成账本实测前，不宣称执行去重完成。


## 2026-09-13 实施结果

事件使用账本为 inference_entry_event_claims_v4。主键保留每个决策动作的记录，唯一键限制同一用户/账户/策略/active_event_id 只有一个有效占用；风险拒绝只把 active_event_id 置空，原记录不删除。completeTrader 先取得账户锁，再读取原交易员快照、校验事件和检查占用，决策、占用及 outbox 同事务提交。重复事件写为 stale/entry_event_already_used，不进入风险执行链。

交易策略显式 entry_event_policy={version:1,mode:'required',timeframe:'M5'} 时，每个开仓/挂单动作必须引用原分析事件 ID；已存在且未声明该政策的策略不自动套用。主动声明 entry_event_id 的动作也必须通过原快照与账本校验。挂单方向按 type 的 buy_/sell_ 判定，管理动作不能消耗入场事件。

risk 使用 inference 已有同事务端口同时写回决策和账本：拒绝后 released，批准后 consumed。terminal uncertain、挂单撤销、结果超时都不会自动释放 consumed。推理事务提交回执未知返回 inference_commit_unknown，并丢弃连接，禁止将其当作未提交回滚重试。

为保留旧数据语义，以 inplace_079_01_entry_event_claims 的迁移完成时间作为账本覆盖起点。模型提示中更早的空记录为 unknown；注册事务再次拒绝起点以前或恰好位于起点的事件，不从空账本推断旧事件未使用。

当前 dev_vue 已兼容升级为 267 步、315 张表，原表行数/行哈希及旧升级校验值未改变。隔离 MySQL 已验证并发唯一占用、风险拒绝释放、批准保留、回滚、提交回执丢失、账户/用户/策略隔离和 DDL 回执丢失后的幂等恢复。实际 MySQL/Redis/Worker 链路已验证模型冻结事件→决策占用→周末风险拒绝→释放；没有真实终端交易。模型响应和行情仍为测试夹具。

基础身份与去重账本已完成。H1/H4 v4 候选已经绑定 required M5 事件配置，仍未激活。M15/M5 独立新机会组合和旧允许事件类型覆盖仍需核对；这些不能由“事件 available”自动替代。核实原文后，15 分钟同向冷却保留建议语义，不列为强制实现阻断。
