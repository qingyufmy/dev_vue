# 观摩主动切换与 Pro 无桥接分析订阅

> 2026-09-05；用户补充确认的产品要求。本文仅记录需求、源码缺口与实施边界，不表示功能已完成或上线。

## 1. 已确认规则

- 观摩模式由用户主动进入、主动退出。没有连接自己的 Bridge、账户离线、会员变化都不应自动替用户进入观摩。
- 进入观摩仍须通过频道授权；退出不要求本人 Bridge 在线，没有本人账户也必须能够退出。
- Pro 用户即使从未连接自己的 Bridge，也可以开启分析策略订阅、接收最新分析和查看本人分析记录。不制造占位 MT4/MT5 账户或虚假连接来满足订阅外键。
- 未连接本人 Bridge 时，不可使用依赖本人终端的实时账户、报价/K 线、持仓、挂单和交易操作；不能启动该账户的 AI 交易员执行或持仓管理。网页显示禁用原因，服务端独立校验。
- 分析订阅属于系统用户；账户级交易执行订阅属于具体交易账户。多账户分别选择策略的能力保留，不能因拆分分析订阅恢复成用户级单一订阅。
- 观摩查看、个人分析订阅、账户执行准入是三个独立维度。观摩切换不启动、停止或改绑个人订阅，不修改后台账户交易开关，也不允许用观摩源执行交易。
- 本次仅明确 Pro 无桥接权益；不顺带扩大 free/plus 权益，不改变已有观摩频道受众规则。

## 2. 数据与安全边界

1. 无本人 Bridge 的分析需使用合法授权、可用且满足时效要求的平台行情来源。分析输入来源与个人终端执行目标分开，不以虚假 owner 关系或任意观摩源替代授权。
2. 平台分析行情来源与观摩频道不是同一概念；无桥接订阅不自动授予任意频道或源用户私有数据的访问权。浏览器平台行情展示需另有明确发布合同，本批不凭订阅权限新增。
3. 行情源缺失、过期或被撤销时，订阅配置可保留，但当前分析应给出明确不可用原因，不用陈旧数据伪造正常结果。来源身份、观察时间及授权证据随分析输入冻结。
4. 已保存且仍有归属权限的个人历史记录不会因离线而删除；历史快照必须标注时间，不冒充终端实时数据。与终端无关的策略、宏观、模型配置等继续按各自权益授权。
5. 重新连接只为后续正常调度提供候选执行目标；仍须校验用户明确开启的账户执行配置、有效信号、新鲜快照和硬风控，不补执行离线信号。
6. Pro 到期应停止新增受该权益保护的调度/交付并通知用户，保留订阅配置与应保留的历史；具体权益矩阵在订阅合同阶段落地，不以 Bridge lease 代替会员校验。

## 3. 当前源码证据与待实现项

- `TradingService.enterObserver/leaveObserver` 和 trading-context HTTP 已有主动切换入口；首页 controller 已调用。退出无账户时当前返回 `blocked`，不能据此把非终端的分析功能一起屏蔽；需按功能能力表达“无执行账户”。
- `MysqlAnalysisScheduleRepository.listDue` 当前仍以 `strategy_subscriptions.trading_account_id` JOIN owner 归属，并把该账户作为分析行情源。`DueAnalysisSchedule.marketSourceAccountId` 必填；因此从未连接账户的 Pro 路径尚未贯通。
- `AnalysisContextBuilder` 已有行情读取端口，但不能将端口的可空 preferredAccountId 当作平台行情授权、来源选择和持久化订阅都已完成的证明。
- 需要在策略/订阅 B2 批次设计用户分析订阅与账户执行关联、独立行情来源、权益检查、调度去重、交付、API/前端能力合同；SQL 只追加迁移，原有账户订阅与记录须映射、对账保留。
- P4B 增加主动退出、无本人账户、失效频道、晚返回响应的验收；无桥接 Pro 的订阅全链路不得仅放进观摩管理 API 中实现。

## 4. 两轮评审与验收门

第一轮（产品/职责）：避免把“没设备”当作“观摩用户”；不增加第三种需要用户理解的模式。区分用户分析与账户交易，但保持多账户不同策略和现有去重能力。进入观摩是浏览器查看行为，不是后台交易总开关。

第二轮（数据/安全/迁移）：当前非空账户依赖是真实缺口，不能仅移除 owner JOIN 或传 null 绕过。实施前审查外键、调度、扇出、计费/额度和数据源证明；两类订阅不得重复收费或重复生成同一分析。新增权益变化、断线/重连、无账户、数据源不可用及跨用户负向测试，不调用真实终端测试交易。

验收至少覆盖：无账户 Pro 创建/开启/暂停订阅；个人 Bridge 离线仍接收合格分析；过期数据不分析；无交易员/交易指令副作用；进入退出观摩不改变订阅；断线不自动进入观摩；退出时无账户或授权已失效仍可完成；多账户订阅互不影响；旧数据迁移计数、映射和分析去重一致。

本次为文档补充。P4B 源码实现及后续订阅结构变更仍须按阶段介绍并取得用户确认，不授权迁移、启动、部署或 MT4/MT5 交易。
