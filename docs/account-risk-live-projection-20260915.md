# 账户风控汇总接线与验证

## 已接通

新增 `worker-risk-summary`，在独立后台进程内每 10 秒按在线账户更新风控汇总。入口已登记到 `ecosystem.v4.config.cjs`，健康端口默认 3030（`V4_RISK_SUMMARY_HEALTH_PORT`）。HTTP API 和 Bridge 网关不承担汇总轮询。

数据路径：完整历史任务及分页证据 → 费用字段和历史余额核对 → 当前所有权、设备凭据、终端连接与新鲜账户/持仓/挂单投影 → 当日风险基线 → 风控汇总与状态事件。汇总只读取数据库缓存，不额外按 10 秒向终端请求全量历史。

桥接的完整历史投影此前没有发送 `history_coverage`。现补充既有合同中的完整性证明，时间固定在分页快照创建时刻，空历史页同样带证明。重新采集的完整任务 `7c429a48-4535-419b-bba8-7b1cf154aec1` 已成功，240 条事实通过页成员、来源和费用核验。未修改旧任务证据。

历史现金合计必须与当前终端余额完全一致，未闭合历史仓位必须与当前持仓标识及手数一致。不支持的资金类型、缺失费用、混合顺序或覆盖缺口均停止更新，旧汇总按已有时效规则变为不可用。历史读取上限为 64 个连续窗口、10000 条事实，超过上限失败关闭。

## 剩余验证与限制

本轮实际验证的是 MT5；当前严格持仓/历史读取端口对 MT4 返回不可用，MT4 风控汇总尚未打通。当前回撤从首次有效快照开始维护，不宣称恢复此前未采集的日内净值峰值。

离线阶段测试不等于真实完整端到端成交。交易员和风控执行消费者尚未启动，桥接交易命令数仍为 0。已向用户确认 MT5 模拟账户及允许的品种、手数和现有持仓操作范围，收到回复后再进行真实分析 → 账户交易决策 → 风控 → Bridge → 终端回执联测。不得为了通过测试放松策略或风控规则。
