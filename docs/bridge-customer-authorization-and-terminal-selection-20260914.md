# 智桥客户授权与多终端接入调整方案

状态：需求复核与设计方案，尚未实施协议变更。依据用户 2026-09-14 对浏览器授权、连接额度、MT4 手动安装、MT5 路径与拖入入口的要求。承接 bridge-design-and-logic-audit-20260914.md。

## 1. 软件授权一次，账户各自隔离

当前已有档案重连不需要再次复制配对码；但 V4 新增档案需要重新配对。目标改为“当前 Windows 用户的这台安装实例授权一次”，不是每次连接或每新增档案都要求网页配对。

1. 首次点击“授权并连接”，客户端创建短时授权请求，打开可信网站确认页；未登录时走现有 SSO，登录后返回原确认页。
2. 页面明确显示网站账号、设备名称、请求时间及授权范围：允许此安装实例登记客户主动选择的本地终端，仍受平台权限及连接额度约束。浏览器需明确确认，不因网站已登录而静默授权。
3. 客户端用专有短时设备凭据按服务端间隔轮询结果。浏览器 URL 仅含定位确认请求的短时标识，不传长期凭据；长期安装凭据保存在 Windows DPAPI CurrentUser。
4. 后续客户在客户端主动选择终端、核对账号后添加档案。服务端以安装凭据登记/授权档案，签发隔离的档案凭据；每个账户仍有独立 Worker、连接世代和数据作用域。不能给各档案直接共用无限权限设备 Token。
5. 客户端重启、正常重连、网页退出不重复要求授权。凭据撤销、到期不能续期、换网站账号、重装/换Windows用户或重大权限变化时重新授权。删除一个档案仅撤销对应档案，不撤销整台软件；撤销整台设备影响其所有档案。

原复制码保留为浏览器打不开等场景的备用方式；设备码只定位同一安装授权请求，不能与旧的档案配对语义混淆。旧档案凭据先保持可用，用户明确完成一次设备授权后再进入新流程，不扩大旧凭据权限。使用 V4 新合同，不接回 V3 `/api/auth/bridge-pair/*` 旧接口。

## 2. 连接额度显示

主窗口固定显示：网站账号、设备授权状态、账户连接上限、当前占用、剩余数量。例“可同时连接 2 个账户，已用 1 个，剩余 1 个”。数值取服务器，按网站账号跨电脑汇总；授权软件和保存离线档案不占额度，真实账户连接才申请额度。

断网显示最后同步时间与“待确认”，不能把未知占用显示为 0。额度不足时保留离线档案，解释哪些连接占用，可跳转网页管理额度；客户端不自动断开另一台电脑的账户。普通账户与平台观摩源分别按现有权威额度模型显示。

## 3. MT4 自动发现与手动安装并行

当前 V4 页面识别的是已在线 EA 会话，还不是完整自动安装向导。目标保留自动发现候选，但不得发现多个终端后擅自选择安装位置。

- 提供“选择已发现终端”“手动选择数据目录”“导出 EA 文件和安装说明”。
- 手动入口引导客户在目标 MT4 使用“文件→打开数据文件夹”，选择该目录并校验 MQL4/Experts 结构；不把 terminal.exe 所在安装目录当成数据目录。
- 安装前显示目标目录及能确认的终端信息；仅复制本软件适配器，发现同名文件先校验并保留可恢复副本。不覆盖用户其他 EA、图表模板或交易设置。
- 若目录无法写入，提供导出文件手动复制。安装完成只表示文件就位；加载图表后的 EA 握手、真实账号和券商匹配后才显示“终端已连接”。
- 终端权限不足时说明如何在目标终端处理；不静默修改自动交易权限，不启动、关闭或登录 MT4。

## 4. MT5 三种定位入口

同一识别服务接收三种入口：自动发现、浏览/粘贴路径、拖入本地文件。入口不同不改变最终身份校验。

- 支持已安装的 terminal64.exe、明确安装目录，以及指向终端的本地 `.lnk` 快捷方式。拖入快捷方式仅解析目标和已知参数（例如 `/portable`），不执行快捷方式命令。
- 如果“启动包”指压缩包、安装器、BAT/脚本或第三方启动器，不能作为已经存在的交易终端直接运行。提示用户先自行安装/启动，再选择真实终端；不猜测链式启动目标。
- 未运行时可以保存候选路径，但提示客户打开终端并登录后识别；不通过探针顺带启动或登录终端。
- 候选展示路径、运行情况和可确认的便携模式；识别成功后展示实际账号、券商、终端数据目录供确认。多候选不自动选第一个，同名/同路径歧义不静默合并。
- 身份绑定需校验所选进程/路径、启动模式、接口返回的实际 path/data_path、账号与券商。识别前后确认终端仍是相同实例；身份变化清除旧识别结论，要求重新确认。

当前代码缺口：TerminalDiscovery 按路径去重；worker.py 的 initialize 固定 portable=False，probe_terminal 返回的是请求路径而非与 terminal_info 的实际路径对照。因此当前自动识别不能称为完美。

MetaQuotes 官方说明 initialize 可指定路径与 portable 参数，必要时可能启动终端：https://www.mql5.com/en/docs/python_metatrader5/mt5initialize_py 。故“调用前发现进程”不等于严格保证永不启动，必须覆盖识别期间终端退出的竞争条件；若当前 SDK 无法提供此保证，应明确保留该验收阻断项，不宣称已满足。

## 5. 两轮复审与实施门

第一轮（客户任务与职责）：默认界面只保留授权软件、选择终端、核对账号、连接状态和额度。Python/Worker由校验过的私有运行时管理。浏览器确认授权替代复制码作为默认入口，手动路径与拖入是自动发现的补充。客户端不承载会员、策略或风控决策。

第二轮（授权、兼容与异常）：设备授权必须防请求错配、确认重放与跨账号领取，支持取消、到期、重复确认及网络中断后恢复。安装授权、档案凭据和账户连接lease分层撤销。网页换账号须重新展示主体。保持旧档案有效，不自动提升凭据。路径解析不执行输入文件，多终端歧义失败关闭；MT4确认数据目录，MT5确认实际返回实例。

实施顺序：先修审查报告中的指令空值、uncertain上下文、在线改配置、双开覆盖；再新增安装实例授权和服务端额度查询合同；接着完善客户端授权/内置运行时；最后做MT4安装与MT5三入口识别。

验收：首次授权/后续重连/新增第二档案/网页退出/设备撤销；跨电脑并发额度与未知状态；多个MT4目录和无写入权限；多个MT5副本、便携版、含空格中文路径、失效快捷方式、终端中途退出/换号。只读识别验收不代替真实交易验收。数据库迁移、安装到用户终端、权限改变及发布仍按对应步骤执行，当前文档不表示已经执行。
