# Bridge 桌面界面整理

用户已批准轻量 Windows 工具方向。本轮实现账号额度区、添加终端主入口、终端列表、分项权限提示及中文异常区；授权、连接、删除和交易执行语义保持既有逻辑。

## 第一轮复核：任务与布局

- 顶部显示软件名称及账号额度；退出放入账号菜单。
- 添加终端为主操作，MT4 安装移入编辑器的平台区域，配对码保留为备用入口。
- 列表保留备注、账号、券商、终端/权限与服务器连接，保持两种连接状态可区分。
- 技术诊断采用详情入口；删除说明保留在已有确认流程。

## 第二轮复核：兼容与边界

- WinForms/.NET 4.8，不新增浏览器内核或依赖；保留系统高对比度。
- 新按钮复用现有授权、忙碌、关闭和删除保护；菜单不得绕过原处理器。
- 采用可伸缩布局与列表宽度计算，空态保留添加入口；选择状态和右键目标保持原有规则。
- 不修改账户数据和运行配置，不执行交易。以严格编译及定向回归验证；原生窗口视觉验收需用户反馈，不能用源码测试代替。
- 产物单独构建并保留本地旧版本；已获用户授权更新及重启桥接。

已将布局提取为 MainForm.Layout.cs，中文状态引导独立为 MainForm.ConnectionGuidance.cs。账号额度区、账号退出菜单、添加主入口、备用工具菜单、MT4 安装入口、空态、动态列宽、行距及开关数量提示已实现。诊断窗口支持选择并复制信息。

### 自动识别交互与失效凭据诊断

- 新增/编辑窗口打开、切换平台自动刷新；明确选择终端后自动识别填入并将档案名设为交易账号。多个终端不自动替用户选择。新档案默认自动连接，已有档案开关保留。
- 撤掉账号/更多下拉，恢复退出账号、配对码接入、MT4安装直接按钮；未授权时隐藏退出按钮。
- HTTP与MySQL只读诊断证实两个旧档案的设备凭据及其父安装授权已撤销，当前软件另有有效授权。用户为有效admin/pro，因此本次401不由套餐造成。不恢复已撤销的记录；客户端将401区分为终端授权失效并给出重新添加提示。
- Core/桌面严格编译与会话令牌回归通过，已更新本地 EXE/Core；无需更新 EA。产物及备份 D:dev_codex.local-runtimeridge-onboarding-fix-20260914。
- 用户另提出额度简化方向：Pro基础1、Plus/免费基础0，桥接读取服务端统一额度。发现当前总额仍写死1+增购，凭据/安装侧还存在套餐校验；套餐调整需同步summary与Gateway原子claim及授权边界。本轮尚未修改或部署该服务端规则。
