# 分析师流程实施记录

本轮沿用现有分析页面和接口，不增加调度配置或数据库表。手动分析选择当前账号可用的已发布分析策略；周期由策略的行情配置决定，不使用首页图表周期覆盖策略。默认品种取当前公共行情标准品种，后缀仍由桥接解析。订阅时间配置沿用顶栏现有入口。

第一轮复核：无记录时禁用详情查询的 pending 状态被误当作正在加载，已修复。补齐策略读取失败、无可用策略和详情失败的明确提示与重试。策略/记录/详情缓存按系统登录会话隔离，记录继续不随交易账户切换。

第二轮复核：手动分析每次生成新幂等键会使网络不确定后的重试变成新任务。现按用户保存未确认请求，同内容重试复用原键，不允许未确认时换策略或品种；服务端确认后清除。冷却到期按任务创建时间计算，避免重试重复延长。结果通知刷新记录；无选中记录时定位真正的结果ID，不能将任务ID当作结果ID。首页已经订阅 market_analysis.created 并刷新最新分析，保持原实现。

验证：分析模块8项测试通过，覆盖空记录、幂等重试、用户隔离、结果通知与已有展示逻辑；trade类型检查通过。浏览器确认当前账号没有可用的已发布分析策略，页面显示配置入口并正确展示空状态。未伪造策略、分析结果或倒计时，未调用真实模型或开启自动交易。

仍待真实验收：配置/发布可用策略与模型后，执行一次手动分析，验证任务完成、完整结果及首页同步；自动分析需由用户确认订阅配置并启用后验证自然调度。现有实时任务通知不等于断线期间的任务状态补查，后续应补只读任务查询以恢复离开页面期间的任务；当前未声称完整链路已验收。

策略配置流程复核：修复确认按钮提前关闭弹窗、清空待发布版本的问题；发布、停用和结束订阅均在成功后关闭，提交期间禁止取消，失败信息保留在弹窗内。新建版本保留已有指标和行情数据计划，避免只编辑提示词却丢失配置；独立行情计划目前保留原配置，不在简化表单中编辑。账户订阅默认选择当前交易账户；清空账户或策略选择后结束对应加载状态。

验证：新增3项回归测试通过，覆盖发布等待确认和两种行情配置保留；trade类型检查通过。浏览器验证新增策略表单与取消操作，未提交测试数据。目前平台ATR策略和道诚实战精选策略均为草稿，首次真实分析使用的策略仍待用户指定。
