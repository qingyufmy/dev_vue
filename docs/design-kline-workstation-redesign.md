# K 线图为主界面的前端重新设计方案

## 1. 现状分析

### 当前架构
- **8 个独立页面**：首页、市场行情、AI 分析师、AI 交易员、AI 风控师、AI 策略师、AI 复盘师、交易记录
- **图表库**：TradingView Lightweight Charts v5.2.1（已在用）
- **布局**：左侧固定导航栏 + 顶栏 + 内容区
- **K 线图现状**：仅在首页（基础蜡烛图+成交量）和分析师页面（缠论叠加）使用

### 当前问题
1. **信息分散**：交易相关数据分散在 4-5 个页面中（行情、分析、交易、风控、记录），需要频繁切换
2. **K 线图被边缘化**：作为交易核心工具，K 线图被压缩在一个卡片中，仅占页面约 30% 面积
3. **操作链路过长**：从看行情 → 看分析 → 下单 → 监控，需要跨 3 个页面完成
4. **持仓/挂单与行情分离**：用户无法直观看到自己的持仓在 K 线图上的位置

### 可用数据
| 数据类型 | 来源 | 实时推送 |
|---------|------|---------|
| K 线 (M1-D1) | WebSocket + HTTP 历史 | `public_candle` |
| 报价 (bid/ask/spread) | WebSocket | `public_quote` |
| 持仓 | WebSocket + HTTP | `positions` |
| 挂单 | WebSocket + HTTP | `pending_orders` |
| AI 分析信号 | WebSocket + HTTP | `market_analyses` |
| 风控指标 | HTTP | `risk.summary.changed` |
| 账户指标 | WebSocket | `metrics` |
| 缠论结构 | 分析快照内嵌 | — |

---

## 2. 新设计目标

**核心理念**：以 K 线图为"画布"，所有交易信息围绕价格走势展开，从"看多个页面"变为"看一张图"。

### 设计原则
1. **价格为王**：K 线图占据 70%+ 的可视面积，永远是第一视觉焦点
2. **上下文不丢失**：持仓、挂单、AI 信号直接标注在 K 线图上，不需要切换页面
3. **渐进式披露**：默认展示核心信息，需要时展开详细面板
4. **一键操作**：在 K 线图上直接看到并操作交易（下单、改 SL/TP、平仓）

## 3. 新布局设计

### 整体结构：三栏式交易终端

```
┌─────────────────────────────────────────────────────────────────┐
│  顶栏：账户 | 净值/余额/浮盈 | 桥接状态 | 时钟 | 设置         │
├──────────┬──────────────────────────────────┬───────────────────┤
│          │                                  │                   │
│  左侧面板 │        K 线图主画布               │   右侧面板        │
│  (可折叠) │        (70%+ 宽度)                │   (可折叠)        │
│          │                                  │                   │
│  AI 分析  │   ┌─ 蜡烛图 + 成交量 ─────────┐  │  持仓列表         │
│  信号卡   │   │                           │  │  (带盈亏色标)     │
│  缠论指标  │   │   🔵 买入信号标记           │  │  挂单列表         │
│  置信度   │   │   ─── SL 线 ─────────────  │  │  一键平仓/改价    │
│  方向    │   │   ═══ TP 线 ═════════════  │  │                   │
│          │   │   📊 持仓成本线              │  │  风控摘要         │
│  品种切换  │   │                           │  │  (3 个核心指标)    │
│  周期切换  │   │   🔴 卖出信号标记           │  │                   │
│          │   └────────────────────────────┘  │  最近 AI 决策      │
│  经济日历  │   报价栏: bid / ask / spread     │  (1-2 条摘要)     │
│  (折叠)  │                                  │                   │
├──────────┴──────────────────────────────────┴───────────────────┤
│  底栏（可选）：快速下单面板 | 执行记录 | 持仓汇总               │
└─────────────────────────────────────────────────────────────────┘
```

### 3.1 顶栏 (Header)

| 区域 | 内容 | 交互 |
|------|------|------|
| 左侧 | 账户选择器 + 平台信息 | 下拉切换账户 |
| 中左 | 净值 / 余额 / 浮动盈亏 / 可用保证金 | 实时更新，点击展开详情 |
| 中右 | 桥接状态灯 + 市场状态 + 自动交易开关 | 状态灯点击查看详情 |
| 右侧 | 时钟(MT5服务器时间) + 通知 + 主题切换 + 用户菜单 | 标准交互 |

### 3.2 左侧面板 (Left Panel — 可折叠，默认展开)

**AI 信号面板**，宽度 240px，可折叠为图标栏。

| 组件 | 内容 | 说明 |
|------|------|------|
| 品种选择器 | XAUUSD / EURUSD / ... | 快速切换 K 线图品种 |
| 周期选择器 | M1 M5 M15 M30 H1 H4 D1 | 按钮组，切换 K 线周期 |
| AI 信号卡 | 最新分析结果：方向↑↓、置信度%、机会标签 | 仅显示当前品种的最新信号 |
| 缠论状态 | 当前趋势方向、中枢位置、笔/段状态 | 从分析快照提取，文字简述 |
| 经济日历(折叠) | 未来 24h 高影响事件 | 折叠显示，点击展开 |

### 3.3 K 线图主画布 (Center Canvas)

**核心区域，占屏幕 70%+ 宽度和 60%+ 高度。**

#### 图层设计（从底到顶）

```
Layer 0: 蜡烛图 (CandlestickSeries)
Layer 1: 成交量 (HistogramSeries, 底部半透明)
Layer 2: 技术指标线 (MA / Bollinger, 可选)
Layer 3: 缠论结构叠加 (笔/段/中枢, 来自 AI 分析快照)
Layer 4: 持仓标记
         ├── 多头持仓: 绿色水平线 + 三角标记 + ticket号
         ├── 空头持仓: 红色水平线 + 倒三角标记 + ticket号
         ├── SL 线: 红色虚线 + "SL" 标签
         └── TP 线: 绿色虚线 + "TP" 标签
Layer 5: 挂单标记
         └── 水平虚线 + 挂单类型标签 + ticket号
Layer 6: AI 信号标记
         ├── 买入信号: 绿色向上箭头 + 置信度
         └── 卖出信号: 红色向下箭头 + 置信度
Layer 7: 交互层
         ├── 十字光标 (crosshair)
         ├── 价格水平线 (可拖拽)
         └── 区域选择 (框选下单范围)
```

#### 图表交互

| 手势/操作 | 行为 |
|-----------|------|
| 鼠标悬停 | 十字光标 + 数据面板(OHLCV + 指标值) |
| 点击持仓标记 | 展开持仓详情浮窗(可操作: 改SL/TP/平仓) |
| 点击挂单标记 | 展开挂单详情浮窗(可操作: 改价/撤单) |
| 点击AI信号标记 | 展开分析摘要浮窗 |
| 右键菜单 | 新建限价单 / 新建止损单 / 分析当前价格 |
| 滚轮缩放 | 时间轴缩放 |
| 拖拽平移 | 时间轴平移 + 触发历史加载 |

#### 图表顶部工具栏

```
┌──────────────────────────────────────────────────────────┐
│ XAUUSD  M15  │ bid 4324.50  ask 4324.80  spread 30 │ 🔍 │
│               │                                        │ ⚙  │
└──────────────────────────────────────────────────────────┘
```

- 品种 + 周期标签
- 实时报价 (bid/ask/spread)
- 搜索按钮 (快速切换品种)
- 设置按钮 (图表设置: 指标开关、图层可见性)

### 3.4 右侧面板 (Right Panel — 可折叠，默认展开)

**交易面板**，宽度 300px，可折叠为图标栏。

#### Tab 1: 持仓 (默认)

| 组件 | 内容 | 交互 |
|------|------|------|
| 持仓列表 | 每行: ticket | 品种 | 方向 | 手数 | 盈亏(色标) | 点击展开 |
| 展开详情 | 开仓价/当前价/SL/TP/浮盈 | 滑块改SL/TP + 平仓按钮 |
| 汇总 | 总浮盈 / 总手数 / 持仓数 | — |

#### Tab 2: 挂单

| 组件 | 内容 | 交互 |
|------|------|------|
| 挂单列表 | ticket | 品种 | 方向 | 类型 | 价格 | 手数 | 到期 |
| 操作 | — | 改价 / 撤单 |

#### Tab 3: 快速下单

| 组件 | 内容 |
|------|------|
| 方向 | 买入 / 卖出 (大按钮) |
| 手数 | 输入框 + 快捷按钮 (0.01 / 0.1 / 0.5 / 1) |
| 止损 | 输入框 + "在图上设置"按钮 |
| 止盈 | 输入框 + "在图上设置"按钮 |
| 参考价 | 自动填充当前价 |
| 提交 | "确认下单" 按钮 |

> **"在图上设置"交互**：点击后进入图上拖拽模式，用户在 K 线图上拖拽出 SL/TP 水平线，松手自动填入价格。

#### 底部: 风控摘要 (常驻，紧凑)

```
日亏 0.00%  回撤 6.71%  持仓 2笔  总手 2.01手
```
4 个小指标卡，仅显示当前值+进度条，点击跳转风控页详情。

### 3.5 底栏 (Bottom Bar — 可选，默认收起)

收起时仅显示一行状态文字。展开时显示:

| Tab | 内容 |
|-----|------|
| 执行记录 | 最近 5 条操作记录 (下单/改单/平仓) + 状态 |
| AI 决策 | 最近 2 条 AI 决策摘要 (方向 + 理由) |
| 策略状态 | 当前运行的策略 + 订阅状态 |

## 4. 标注系统设计 (Chart Overlay System)

这是新设计的核心差异化功能。

### 4.1 持仓标注

```
多头持仓示例:
                    ┌─────────────────┐
   ═══════════════ TP 4380.00 ═══════ │ (绿色实线, 右侧标签)
                    └─────────────────┘
        ╱╲
       ╱  ╲  当前价 4324.50
      ╱    ╲
────────────── 开仓 4322.29 ── ticket #833191449 (绿色水平线)
                    ┌─────────────────┐
   - - - - - - - SL 4307.00 - - - - │ (红色虚线, 右侧标签)
                    └─────────────────┘
```

- 持仓线显示在开仓价位置，带 ticket 号
- SL/TP 线实时跟踪，可拖拽调整
- 悬停显示完整信息浮窗

### 4.2 AI 信号标注

```
买入信号:
    ▲
    │ 92%     (绿色向上箭头 + 置信度)
   ╱╲
  ╱  ╲
 ╱    ╲
```

- 信号标注在分析时间对应的 K 线位置
- 不同置信度用不同大小/透明度区分
- 点击展开完整分析摘要

### 4.3 缠论结构叠加

复用现有 `AnalysisChart` 的缠论叠加逻辑:
- 笔: 蓝色折线
- 段: 黄色折线
- 中心: 灰色虚线矩形
- 分型: 圆点标记

## 5. 快捷操作设计

### 5.1 图上下单

在 K 线图上右键 → 弹出快捷菜单:
```
┌──────────────────────┐
│ 📊 分析此处价格        │
│ ─────────────────── │
│ 🟢 在此价位买入限价单   │
│ 🔴 在此价位卖出限价单   │
│ ─────────────────── │
│ ⚙ 图表设置             │
└──────────────────────┘
```

### 5.2 拖拽设置 SL/TP

在持仓详情中点击"在图上设置"后:
1. K 线图上出现一条可拖拽的水平虚线
2. 用户上下拖动到目标价位
3. 松手确认，自动填入 SL/TP 输入框
4. 底部显示"确认修改"按钮

### 5.3 一键平仓

持仓标注上显示小 "×" 按钮，点击弹出确认对话框:
```
确认平仓 XAUUSD #833191449 ?
手数: 1 手  |  当前浮盈: +$588
[取消]  [确认平仓]
```

## 6. 响应式设计

### 桌面端 (≥1280px)
三栏布局完整展示: 左面板 + K 线图 + 右面板

### 平板端 (768px-1279px)
双栏布局: K 线图 + 右面板(可切换为底部抽屉)
左面板折叠为图标栏

### 手机端 (<768px)
全屏 K 线图 + 底部抽屉
- 上滑: 持仓/挂单列表
- 下滑: 下单表单
- 左侧滑: AI 信号
- 标注系统保持可用，但标注密度降低

## 8. 技术实现要点

### 8.1 图表库
继续使用 **TradingView Lightweight Charts v5.2.1**，扩展以下能力:
- 多 Layer Series (已有): CandlestickSeries + HistogramSeries + LineSeries + Markers
- 自定义插件: 持仓线/SL-TP线/信号箭头 作为图表插件
- 交互层: 自定义右键菜单、拖拽定价线

### 8.2 状态管理
- K 线数据: 独立 composable，支持多品种/多周期缓存
- 标注数据: 从 positions/orders/signals 实时更新，映射到图表坐标
- 面板状态: 左右面板折叠/展开/宽度 保存到 localStorage

### 8.3 实时更新
复用现有 WebSocket 基础设施:
- `public_candle`: K 线实时更新
- `public_quote`: 报价栏更新
- `positions` / `pending_orders`: 标注系统更新
- `market_analyses`: AI 信号标注更新

### 8.4 性能优化
- K 线历史数据分页加载 (已有实现)
- 标注数据按可见时间范围过滤渲染
- 面板内容懒加载 (AI 决策列表、执行记录等)

## 10. 关键设计决策点（待确认）

1. **新工作台是否替代原首页？** 建议是，原首页的卡片式布局信息密度太低
2. **是否保留原 `/trader` 页面？** 建议保留作为"高级模式"，新工作台为默认
3. **K 线图默认周期？** 建议 M15（兼顾短线和中线视角）
4. **左右面板默认状态？** 建议都展开，但记住用户上次的折叠偏好
5. **手机端是否需要完整功能？** 建议简化为: K 线图 + 快速下单 + 持仓概览
