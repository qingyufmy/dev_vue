# 策略声明的场景风险额度

本项在已授权角色迁移范围内扩展通用 risk_budget，不按策略 ID 或名称判断行情。v1 固定额度保持兼容；v2 声明总上限、默认上限以及 market_regime_limits。各值均为正十进制百分数字符串，默认值及分支值不得超过总上限。

场景只读取已校验交易员快照中的原分析 result.marketRegime，校验分析 ID、内嵌内容哈希和整个快照哈希。交易员动作不能指定或覆盖场景。未知、缺失场景使用显式默认额度；H1/H4 候选设为 0.5%，只有精确 h1_continuation 可使用 1%。分档计算和显式手数审核共用最终额度，单动作额度、账户额度仍只能进一步收紧。风险提交事务重新读取原证据及策略配置，任何变化均拒绝写入。

场景分类仍是分析师依策略形成的判断；此机制证明确定性额度执行，不证明模型对缠论场景分类正确。原策略条件及档位上限仍需语义验收，不因绑定风险配置自动启用候选。不新增表、不回填旧版本、不调用真实模型或终端。

第一轮复核（职责和覆盖）：场景到额度的映射属于策略配置；inference 仅提供冻结分析场景，risk 解析配置并执行额度。避免让交易员自报宽松上限，避免将 H1/H4 写死在通用服务端。未知场景使用保守默认，管理动作不会因无法分类而丧失减仓路径。

第二轮复核（兼容和异常）：v1 解析及原上下文形状保持不变。v2 严格字段、最多32个场景、十进制定点比较，不使用浮点比较额度。原分析关联和哈希、未知场景、缺失动作额度、显式超额手数以及提交前场景/配置变化均定向验证。候选保持不可执行；回退只需继续使用原 v1 候选，已应用迁移不变。

## 实施及验证

已实现版本化预算解析、冻结原分析场景投影、风险上下文选择与审计，以及现有风险事务中的原证据重验。73项服务端测试和13项候选/转换测试通过，服务端类型、构建、边界及109项API合同通过。已只读生成H1/H4 v5候选；没有DDL/DML或真实模型/终端调用。场景分类的策略等价性仍未验收，候选保持不可执行。
