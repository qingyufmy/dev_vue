## 读取验收发现的复盘结构缺口

记忆列表SQL依赖strategy_memory_pending_updates_v4，该表及父复盘表尚未纳入241步现库升级。采用012既有复盘SQL及049写回执SQL，排除已存在的记忆库、修订和注入日志结构；其余13条DDL作为新的追加步骤，原SQL/既有checksum不变。先在完整295表空参考库验证全部外键和DDL，再在带数据恢复库升级、重放及核对旧表摘要，最后应用当前库。不能把旧strategy_memory_pending_updates表直接改名当作目标表。

补充第一轮复审：以完整复盘聚合补齐缺失结构，避免为列表移除pending_count或隐瞒缺表；迁移只增加12张表及13条步骤记录，已迁入的4个记忆库/40修订不动。第二轮复审：跳过的3张记忆表使用现库已验证结构；新复盘环形外键按原顺序在建表后追加，所有依赖在完整参考库核对。缺表启动门禁纳入新步骤，不启动复盘Worker，不把空复盘表视为旧复盘历史数据已迁移。
