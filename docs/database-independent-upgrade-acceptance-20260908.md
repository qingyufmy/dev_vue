## 两轮收口复核

第一轮核对目标范围：学习、模型或单个页面不能代表全库；已补全原字段、反向目标字段、显式索引、关系与特权对象。根依赖的延期必须有具体模块和重新启动条件；旧源保留不等于全域规范化完毕。

第二轮核对数据与异常：恢复副本先行、同连接升级锁、147步checksum和中断恢复、全表原值/结构/自增对账、真实MySQL约束拒绝证据与最新全库一致性检查已核验。模型索引显示顺序故障通过精确描述重排解决，未修改已执行SQL/步骤校验和。剩余业务映射、压测及公网覆盖需要后续验收，不能从本报告推导上线就绪。
