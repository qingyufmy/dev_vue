# 前端在线账户默认选择与顶栏切换

- 顶栏仅列出服务端账户目录中 bridgeState=online 的本人交易账户，选项只显示平台和交易账号；仅同时有两个或更多在线账户时显示选择器，零个或一个时隐藏。
- 默认优先保留仍在线的当前账号，否则选第一个在线账号，不再回退到目录中第一个历史离线账户。明确进入的观摩模式不会被自动替换。
- 切换使用既有 runContextCommand 的 CSRF、revision、幂等和恢复路径，服务器成功后应用共享上下文。页面以账户/模式/观摩频道为 key 重建，旧页面卸载取消旧请求与实时连接，防止不同账户数据混用。
- 顶栏每 5 秒同步账户在线目录和权威上下文，校验登录代次与并发上下文变化；首页默认选择同样使用在线规则。
- 首页移除重复的本人账户选择器，保留观摩源入口；快照暂不可用时，标题可使用权威账户目录显示平台、账号和服务器，金额继续显示未知，不编造资产。

验证：trade 原有及新增默认选择测试共 221 项通过，追加顶栏组件测试 3 项通过（过滤及实际上下文切换、保留观摩、无在线账户）；类型检查、构建和前端边界门禁通过。本地浏览器确认当前 MT5 860058 顶栏与首页一致，菜单只有 MT5 与账号。390px 视口 DOM 宽度及 scrollWidth 均为 390，无横向溢出，验证后已恢复视口。

当前本地只有 1 条连接额度，多在线账户切换采用组件测试，不宣称双真实账户同时在线验收。金额快照和实时行情链路不是本次账户切换验收的替代证明。未部署公网，继承工作区改动未混合提交。
