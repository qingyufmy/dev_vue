# 自动分析编辑简化

单在线账户直接进入编辑；多在线账户按 MT4/MT5 和交易账号分组显示订阅策略与接收状态，点击编辑进入对应订阅。一个账户多订阅时，编辑页提供当前订阅选择。没有可用订阅则进入新增。

运行状态不再单独展示。保存时开启接收自动分析映射 active，关闭映射 paused；历史 paused + analysisEnabled=true 正确显示为关闭。AI 交易员留在订阅内，顶栏交易开关命名交易发送，不合并账户发送权限和策略判断设置。

布局沿用现有 Sheet、Field、Select、Switch 和设计令牌，账户列表按卡片分组；列表只在打开时读取，保留加载、失败和重试。

验证：7 项定向测试覆盖单账户直达、多账户编辑目标、启停字段及既有运行状态行为。浏览器确认单在线账户直接打开编辑并显示多订阅选择；真实环境没有同时在线的多账户，因此多账户使用 Mock 验证。没有保存真实配置、开启交易或发起分析。

剩余事项：继续验收风控页面的规则编辑与详情展示。继承工作区未安全拆分，不整体提交推送。


## 后续交互检查

- 订阅读取中使用独立加载界面，不再把读取显示为正在保存；读取失败显示中文原因及重新读取按钮。
- 指定订阅已消失时不显示默认新增表单，避免误创建。
- 保存完成时核对当前编辑会话，旧响应不会关闭后来重新打开的编辑面板。
- 定向测试 15 项通过，交易前端类型检查通过；浏览器验证单账户直接打开道诚订阅编辑页，取消后返回分析页，顶栏显示实际倒计时。
- 保存及异常分支使用模拟请求验证；本轮未修改真实订阅或交易发送开关，也未主动请求模型。
- 下一步检查 AI 交易员从分析结果到交易建议的页面衔接，并继续整理用户可见提示。
