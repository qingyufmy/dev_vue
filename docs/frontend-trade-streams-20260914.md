# 前端真实持仓与挂单同步（2026-09-14）

## 完成范围

- 桥接增加独立只读采集线程，每轮完成后间隔约 5 秒采集持仓与挂单，不在心跳线程执行终端 I/O。
- 采集前后核验精确终端账号与券商服务器；缺失、失败、过期或分页未完成的查询不发布空集合。当前单次全量边界为 500 条，超过边界会保留未确认状态，不截断后冒充全量。
- MT4/MT5 字段标准化为已有 V4 positions / pending_orders full snapshot 合同。保留长 ticket / position_identifier、当前剩余挂单手数、交易类型和止损限价；零止损止盈转换为 null。归因不从 magic/comment 猜测，维持 unknown。
- MT5 Worker 在原始查询字段外添加 UTC 时间字段，复用现有适配器时钟转换；缺少时间不伪造时间，转换不能完成则本轮不发布。没有更改账户级可信时钟权限。
- Bridge ACK 处理支持这两类流；服务端复用已有可信投影、归属与 epoch 校验、Redis 发布和浏览器按账号订阅。
- 首页以有效快照 revision 区分等待同步与已确认零条。浏览器拒绝跨账户行和旧 revision 的持仓/挂单事件。
