# 前端真实账户数据第一阶段（2026-09-14）

## 已完成

- 桥接复用已通过账号/服务器精确校验的 account.snapshot，每约 10 秒上报余额、净值、保证金、可用保证金、浮动盈亏、货币、杠杆及交易权限。身份探测与传输线程分离，心跳线程不新增终端 I/O。
- 上报 full snapshot，以观测 UTC 毫秒为 revision；同一次观察不重复发送，新的连接 epoch 会重新发送最新有效快照。超过 25 秒的本地观察不发送；服务端拒绝过旧或明显来自未来的观察。
- 服务端从已授权 route 确定账户和终端身份，通过既有可信投影事务和归属/epoch 校验落库，再经 Redis 发布浏览器事件。金额使用定点文本，合同限制与 DECIMAL(24,8) 对齐。
- 未取得终端时钟证据时保持 unavailable，不从账户金额推测服务器时区。
- 浏览器 realtime 服务已在本地 3011 启动，沿用本地 API 的认证配置。HTTP 首次读取和断线后回读保持不变。
- 修复历史 K 线单条 revision 被当作实时流游标，导致 subscription.resync_required 无休止重连的问题。历史 K 线没有实时游标时使用 null；账户与其它已有投影仍校验版本。
- 实时账户事件增加可选 leverage / trade_permission；新消费者保留旧生产者兼容，明确提供的权限变化会更新页面。原先没有账户快照时收到指标事件会重新读取 HTTP 快照。

- Bridge .NET 4.8 x86 checked、warn-as-error 构建；账户生产者 smoke 覆盖定点金额、精确路由、权限、重复观察、epoch 重连、过期观察。
- 服务端 31 项定向测试通过：账户合同/解析正反例、过期拦截、流入口和可信投影垂直链路。
- trade 225 项测试通过；补充权限/杠杆后 20 项相关测试通过。trade 构建、前后端边界检查及四应用类型检查通过。
- 本地真实 MT5 860058：首页显示 9,225.04 USD、杠杆 1:500；浏览器收到连续 account.metrics.changed，观察版本持续前进。
