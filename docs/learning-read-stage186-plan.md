# 学习域新表读取实施范围

承接已完成的学习域回填，新增主站课程列表、详情、个人学习进度只读链路。读取 learning_* 与当前 memberships，不写课程/进度、不改旧表、不切换旧网站运行实例。

- 公共课程列表只返回已发布课程摘要，用 sort_order/id 游标有界分页，不读取媒体或用户进度。
- 详情只返回已发布课程；内容权限按 free/logged_in/plus_pro/pro_only 判断，会员来源通过 commerce 端口提供，缺失/过期不扩大权限。主站仅识别 www-web 会话。
- 有权限时返回有界课节、本人进度和可公开导航的媒体地址；绝不把本地视频路径或对象存储键作为浏览器地址直接返回。
- 主站新增课程列表与详情，沿用现有组件与设计；日期显示北京时间，未登录提供返回当前课程的登录入口。
- API 使用 /api/v4/learning，主站 Host 限制、no-store、稳定错误码与 OpenAPI 合同；不接受客户端 user_id。

## 第一轮复核：覆盖与职责

保留旧课程发布/访问语义，列表与受保护资源分开；membership 读取归 commerce，学习域不读取 auth 内部表。仅建立读取流程，不借机新增播放器 SDK、自动播放、资源签名或学习进度写入体系。

## 第二轮复核：兼容与数据

未发布课程 404，越权不给媒体和他人进度；大整数时长保留文本，NULL 进度不造零值；UTC 输出 Z，页面固定北京时区；列表及课节均有界，加载/空/错误/锁定状态可恢复。本地单元/注入测试及真实数据库读取为证据，不冒充真实 SSO/公网验收。
