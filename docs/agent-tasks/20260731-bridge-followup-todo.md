# 量见智桥后续待办（2026-07-31）

## 浏览器授权取消后允许立即重试

- [x] 用户点击“连接账号”后再次点击时，若旧授权仍在进行则不重复打开网页；界面询问用户是否已关闭原网页，只有明确确认“重新打开”后才废弃旧轮询并创建新的授权会话。
- 当前根因：核心的 `pairing_active` 会持续保持到授权成功、授权码在 10 分钟后过期，或进程退出；关闭外部浏览器不会通知核心取消会话。
- 同时补充 `bridge_pair_in_progress` 的中文可解释提示，作为并发点击保护，不得用它替代主动重试能力。
- 回归验收：覆盖首次打开后关闭网页、立即再次点击、连续快速点击、旧轮询迟到返回、授权成功、授权过期和退出账号场景；保证只有最新一代授权结果可以写入凭据。
- 完成情况：普通配对请求保留防重复保护，新增明确的重新配对动作；配对代次在凭据写入前通过互斥提交门再次核对，退出账号会同步使所有旧轮询失效，界面会先说明旧页面可能仍在打开并由用户决定是否重开。

## 授权页面发起限流

- [x] 服务端对 `/api/auth/bridge-pair/start` 使用独立限流器，同一 IP 默认 10 分钟最多发起 6 次，超过后返回 HTTP 429、`Retry-After` 和稳定错误码 `bridge_pair_start_rate_limited`。
- 授权确认、令牌轮询和其他登录操作不占用该独立额度，避免正常完成一次授权的后续请求被误伤。
- 客户端保留单次授权防重复打开，并将限流错误显示为可操作的中文提示；限流窗口与额度可通过 `BRIDGE_PAIR_START_RATE_LIMIT_WINDOW_MS` 和 `BRIDGE_PAIR_START_RATE_LIMIT_MAX` 调整。
