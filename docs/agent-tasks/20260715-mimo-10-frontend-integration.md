# Mimo Task 10：模型、策略、风控、复盘与记忆前端整合

## 前置

- Task 01–09 后端/API 已审查通过。
- 分支：`dev_codex`。
- 前端为 Vanilla HTML/CSS/JS，无构建步骤。

## 目标

按总方案完成统一前端信息架构，准确展示权限、来源、有效值和状态，不在浏览器复制服务端权限逻辑。

## 必须实现

1. 导航：模型管理、推理策略、交易、风控中心、历史、复盘与记忆；管理员增加全局风控、账户审核和审计。
2. 模型管理独立页面：用户模型列表、默认模型、测试连接、当前来源；管理员共享 manual/auto/review/compression 开关和配额。
3. 手动/自动页面移除重复 Key 编辑，只显示有效模型和来源并链接模型管理。
4. 策略页显示 platform/private、所有者、绑定/继承模型、memory mode、品种、AI 手数平台范围、风控档案和执行状态。
5. 风控中心按账户显示用户值、平台范围、策略限制、最终有效值、待生效倒计时和 Kill Switch。
6. “价格与成交”明确显示市价漂移、挂单百分比、挂单 ATR、成交滑点、点差和报价年龄。
7. 执行详情显示 AI 建议手数、风险上限、最终手数、规则调整、参考价和实际偏差。
8. 管理员全局风控分离默认/范围/锁定值，显示用户风险状态、恢复申请和审计。
9. 复盘与记忆页：待生成、待确认、已确认、内容有问题、经验、压缩版本。
10. 复盘详情证据只读、正文可编辑；按钮文案明确“内容准确并加入记忆/内容有问题继续修改”。
11. 分开显示交易流程问题和复盘内容确认；展示版本、证据缺失、模型来源、Token 和失败重试。
12. 平台共享策略选 personal memory 时提示转逐用户推理和成本变化。
13. 用户只能看到本人内容；管理员按钮只在有服务端权限时展示，仍以 API 403 为准。
14. 使用平台共享模型处理私有策略、复盘或记忆时，向用户显示平台凭据调用第三方模型和可能的配额限制；不向管理员暴露用户正文。
15. 保持响应式、加载/空/错误/禁用/待生效状态和中文文案。
16. 添加 DOM/路由/权限回归测试；不得把密钥放入页面 state 或响应。

## 非目标

- 不重新设计后端语义。
- 不绕过 API 直接推算有效风控。
- 不大范围改品牌视觉或无关页面。
