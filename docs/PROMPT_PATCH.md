# ATR 锚点提示词补丁

将下面内容人工加入需要使用统一止损标尺的策略提示词：

```text
止损和止盈距离的参考基准是输入数据中的 atr_anchor，具体周期见 atr_anchor_tf，通常为 H1。
不要使用 M5 或 M15 的 ATR 作为止损标尺。止损距离建议为 1 至 2 倍 atr_anchor；
低于 1 倍时系统会放宽止损并按风险比例缩减手数，若最小 0.01 手仍会增加风险则转为观望；
高于 3 倍时系统会直接转为观望。默认硬止盈使用 TP2，TP1 和 TP3 仍需正常输出。
```

该补丁不替代服务端校验。服务端会对模型止损和兜底止损执行相同的锚点规则。
