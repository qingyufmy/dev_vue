# AI 策略师编辑设置

本轮补齐交易端同页编辑：名称、说明、状态、标准品种、使用模型；交易策略额外选择市价、限价、突破和止损限价入场。行情数据、运行间隔、缠论、EMA34 与价格行为设置继续保留。

## 保存与权限

编辑通过现有创建版本接口提交可选 name、description、status，与配置和新版本在同一事务内保存，共用并发版本与幂等回执。启用时该新版本成为当前版本；停用使用现有 draft 状态，停止参与运行并保留历史。旧客户端不传新增字段时仍保持“新建未发布版本”的行为。公共策略仍在数据库事务内核验管理员身份，重放回执也重新核验。

配置沿用现有 config_json，无数据库结构变动，不需要新增迁移。HTTP 域源、运行校验与生成类型已同步。

## 运行行为

- symbols 使用不带券商后缀的标准品种；为空兼容原有不限品种设置。订阅保存及分析、交易上下文构建都会检查支持范围。券商后缀仍在既有品种映射链路处理。
- model_profile_id 优先于用户的用途模型分配；未指定则沿用现有选择。指定模型不可用时明确失败，不擅自切换其他模型。原有模型权限、验证状态和公共共享条件继续生效。
- entry_methods 使用现有交易执行规则；至少选择一种，不扩展终端能力或绕过风控。

## 本地验证

24 项服务端定向测试及 5 项前端定向测试通过，覆盖字段保留、标准品种校验、指定模型无静默回退、管理员权限、原子保存和回执重放。交易端类型检查、服务端生产构建和合同生成一致性通过。浏览器确认编辑面板字段显示正常；没有代替用户提交当前策略，也没有发送交易指令。

本地接口与分析进程已重新载入构建。此次不启动交易执行进程；真实交易联测仍按此前待确认的测试账户范围执行。
