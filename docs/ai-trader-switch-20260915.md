# AI 交易员顶栏开关

顶栏控制当前账户所有未结束订阅的交易员。开启只启用已配置交易策略、正在接收分析的订阅；没有可用配置时打开编辑。关闭关闭所有这些订阅的评估与发送，保留分析、策略绑定、接收时间。多个订阅一次事务保存，任一版本冲突全部不保存。

复审一（已由 2026-09-20 单一开关决策替代）：订阅只使用 `trader_enabled` 作为 AI 交易员入口；`trade_send_enabled` 仅保留为兼容列，不再参与执行判断。账户交易权限与确定性风控保持独立硬门槛。

复审二：所有权和账户锁、订阅集合及版本校验、幂等回执一起提交；关闭递增订阅版本，已有评估和待发送动作通过现有版本核对失效。已交给桥接的命令不宣称撤回。恢复开启也不能复活旧版本任务。不自动开启实盘订阅来验收。

验证：定向事务和界面测试、类型与合同生成检查；部署及真实交易验收单独进行。回滚代码不反向修改用户保存的订阅状态。

验收记录：服务端 14 项定向测试、前端 9 项测试通过；服务端构建、交易端类型检查、HTTP 生成一致性通过。本地 API 已重启且 ready，浏览器已确认顶栏显示。未切换真实账户开关或发送交易。工作区有大量继承改动，无法安全拆分本次提交，未推送。
