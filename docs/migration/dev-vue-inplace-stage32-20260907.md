# 同库升级第三十二批：交易员排队和返回复查

TraderWorker 新增必需的 TraderWindowGuard，生产入口接入 MysqlTraderWindowGuard。按任务冻结的用户、账户、订阅ID/revision、交易员策略/version读取当前active、trader_enabled及当前owner；在短事务中共享读取窗口与有来源时钟。不存在、版本变化或窗口关闭均拒绝，事务提交/回滚后释放连接，模型I/O始终在事务外。

复查点包括准备前、每次模型调用前（含重试）、模型返回后落库前。准备失败使用failQueuedTrader；运行中的明确窗口/订阅冲突通过既有fencing失败路径结束，不重试模型，不完成可执行决策。窗口未启用保留既有行为，窗口外signals_only仍不会允许账户决策。

新增5项回归，连同18项交易员/窗口测试共23项通过；服务端类型检查、构建通过。覆盖四个检查点关闭、精确订阅版本参数、正常提交与拒绝回滚均释放连接。测试使用模拟数据库与模型，本批没有真实数据库写入或角色启动。
