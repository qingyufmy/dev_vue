## 两轮复核

第一轮检查需求与职责：课程/课时继续保留原内部 ID，公开 episode_id 独立；媒体不伪造预分配 ID，不把外部 URL 当主键。调整存证接口为异步同连接回读，避免用进程内写入结果缓存作为恢复证据。旧计数、标志和空定位符保留在来源存证，不冒充已迁移资源事实。

第二轮检查数据、异常和恢复：把媒体绑定纳入独立审核，既比较类型集合和顺序，也比较实际 ID；存证之前验证三表完整内容。缺失媒体、内容变化或来源变化使事务失败，不能生成成功存证。父实体 receipt/ID map 和完整媒体映射分别承担稳定 ID 对应与数据库生成 ID 的归档职责；不能只检查父实体 receipt 就声称整个课程导入完成。
