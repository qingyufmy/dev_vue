# 阶段 92：支付匹配最终行转换

实现 [支付匹配来源绑定](payment-match-row-binding-20260907.md) 与 preparePaymentMatchRows，生成 payment_matches 的 21 个物理字段，绑定父订单 ID/来源、精确期望金额、时间和资产合约证据，并完整保留监听及订单原值。无链上证据不生成交易，不启动监听。

29 项定向测试通过：匹配最终行 11、订单最终行 12、监听来源 6。覆盖窗口采用订单创建时间、监听 UTC 时间独立保留、NULL、集合/行/地址/证据错误、非 ASCII 合约、越界偏移和无效窗口、重复依据及已有哈希缺链上事实。

本轮仅源码和合成测试，没有数据库读取或写入。当前真实历史时间和资产依据尚未冻结；已认领交易分支、匹配 writer/同事务来源证据及完整独立对账仍待实现。此前真实 MySQL 整批证明针对订单流，不能当作匹配流的真实验收。
