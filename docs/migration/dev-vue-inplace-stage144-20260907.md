# 阶段 144：配置编辑数据一致性控制器

新增admin局部createSettingEditorController，将实际读取、版本化写入及未知恢复状态组合为页面可调用的控制器。使用请求代次忽略切换后的旧响应；共享API客户端核对响应namespace/key必须等于请求。缺失与读取错误保持独立状态，不拼造默认配置。

当前值为protected、加载中或未读取时不允许保存。未知提交保持原scope及请求，禁止切换读取；恢复继续使用原版本/正文/编号。提交确认后清空旧表单再刷新，刷新失败只影响读取状态，不把已提交写入降为未知或重发。

suspend清空读取数据并使在途读取失效；在途写入确认后也不能重新填充已暂停页面。待恢复请求仍由同用户写会话保存，不能跨用户恢复。UUID生成器返回值现先通过格式校验，避免无效编号留为待恢复操作。

API客户端22项测试、admin11项测试通过；admin类型及构建、API客户端类型检查通过。新增行为覆盖配置身份不匹配、迟到读取、未知时切换拒绝、原请求恢复、成功后刷新失败、protected/跨用户写入以及保存期间暂停。
