# U2 只读预检与稳定源读取合同

2026-09-06，继续U2框架；不执行DDL/DML，不启用业务writer，不把U1清单标为可执行。

第一轮复审：复用现有schema fingerprint与U2规范化hash思路，提供只读预检和固定主键分页模块；不搭ETL服务，不接业务API。预检区分源/目标实例、实际结构、目标迁移记录和波次阻断。源读取使用调用者明确指定的冻结镜像，不能默认回退 `.env` 活动库。

第二轮复审：跨页复合PK比较交给MySQL的真实类型/排序规则，不按JS字符串排序大整数；INT按十进制字符串、文本按明确字符集、二进制按hex绑定参数。不使用OFFSET。读取保留NULL、空值、原DATETIME墙钟及类型；采用SQL逻辑值二进制表示的hex信封并hash，不声称是原备份字节或InnoDB物理存储字节。FLOAT/DOUBLE、无主键、前缀/降序主键和未知字符集先失败关闭，后续专门处理，不能转Number损失精度。

实际结构指纹只排除SHOW CREATE最后表选项行的AUTO_INCREMENT当前计数，保留字段默认值/生成表达式/索引/约束。原B1备份指纹不改；两种指纹用途分开。只读schema核对不能证明快照内容未变，`snapshotHash`绑定只代表声明的冻结来源；最终回填前还需已恢复备份的内容验证及无写入/无DDL窗口。

reader独占一个只读事务直到close，页数/行数/载荷有上限，同一reader不允许并发页读。普通失败回滚并关闭；单页超限保留事务和原游标，允许缩小页重读，单行仍超限则必须关闭并等待专用读取路径，不能截断。游标绑定声明快照、实例/库、表元数据和有序PK。跨进程使用游标前必须重新验证冻结源，不能以结构没变代替数据没变证明。

当前没有受控apply CLI。模块结果即使结构相符也保持`readyForBackfill=false`，等待领域转换、波次批准和内容证据接入；预检不会把普通JSON布尔值当作真实写入授权。

## 实现与复核结果

- `scripts/lib/v4-backfill-preflight.mjs`：比较显式源/目标实例及库名、实际结构和目标迁移记录；拒绝视图、可执行schema对象和非InnoDB表。预检仅发SELECT/SHOW，不修改事务或数据库。结构枚举依赖账号具备完整元数据可见性，权限不足时的空对象集合不能作为不存在的生产证明。
- `scripts/lib/v4-backfill-source-reader.mjs`：固定UTC会话、10秒SELECT执行上限、REPEATABLE READ只读一致快照；复合主键分页保留大整数和二进制，文本使用数据库排序规则。每页1–500行，规范化结果最多2MiB；每个reader最多1000个成功页、64MiB累计结果，查询文本最多256KiB。SQL先检查字段总长度再返回hex，阻止巨大字段无界传输；hex及封装开销另在结果端检查。预算耗尽关闭reader；后续只能在重新核实冻结源后以游标继续。
- 调用者须提供独占、无活动事务的专用连接，在`finally`中关闭reader并结束连接；模块不取得/释放连接池所有权，不恢复会话设置，不得直接将连接还池给业务使用。回滚失败销毁连接。当前没有数据库连接入口、业务writer或迁移执行命令。
- 复核补充：拒绝非InnoDB源以保证所选快照模式适用；复制输入游标避免等待查询时被外部修改；区分单页可缩小重试与全reader预算耗尽；查询错误脱敏，并发调用不能关闭正在读取的事务。

`pnpm exec vitest run tests/v4-`：30文件236项通过，本批13项覆盖游标、类型/NULL/逻辑值hex、超限、结构漂移、非事务引擎、并发及失败清理。数据库调用使用替身；尚未证明实际MySQL排序、快照、权限可见性或断网行为，测试中的时间/金额文本也不是实际数据库类型转换验收。未连接数据库，未执行DDL/DML，未修改既有SQL或冻结清单。
