新增 `v4-settings-value-contract.mjs`，精确覆盖阶段 124 的 59 条全局候选；6 条用户偏好和10条旧键不进入此注册表。当前库54条非凭据候选完成两次只读核查，全部符合基础类型规则，原八字段 SQL 行 hash 与全量盘点一致。5条凭据键不参与 value 查询，见 [当前值核查](dev-vue-settings-values-review-20260907.json)。

## 类型与兼容边界

| 类型 | 处理 |
| --- | --- |
| boolean | 仅接受原文本 true/false，不用 truthy、Number 或大小写折叠 |
| integer | 规范十进制整数文本，按具体键检查范围，保留字符串，不浮点转换 |
| enum | 按旧管理合同白名单检查，保留七牛旧区域别名 |
| string | 原字符串保留并验证 UTF-8/长度；地址、URL、邮箱、HTML 的业务校验独立完成 |
| json_array | 验证数组语法和长度，不以此证明菜单/工具项内部字段、链接或渲染安全 |
| credential | 保持密文不透明；合成测试中的 envelope 形状匹配不证明解密成功、密钥可恢复或调用服务可用 |

NULL、空串、缺失不合并，迁移校验不补默认值、不 trim、不重写原字节。每个结果只含类型和待决条件，不返回原 value。所有配置默认 restricted，凭据为 secret；公开投影应另建明确白名单，不能沿用“类别公开所以类别内所有键均可公开”。

旧 SMTP port 读取使用 Number(value)||587，secure 仅等于字符串 true 时生效；本次实际值满足严格类型，仍不把旧 fallback 擅自变成迁移默认。旧存储连接测试时间和错误文本仍按原字符串保留，不能当作可信 UTC 或有效存储连接证明。
