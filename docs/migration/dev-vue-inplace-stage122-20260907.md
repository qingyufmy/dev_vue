# 阶段 122：钱包规范读取器

新增 `mysql-wallet-address-reader.ts` 并从 commerce 公共入口导出。按 chain 和 id 游标分页，默认 100、最大 200，使用 limit+1 判断下一页。返回实际登记的 addressIndex，不从 COUNT 推算派生范围；ID、索引和 revision 均以字符串承接。

显式读取登记字段及托管三字段，UTC 时间保留毫秒，源 NULL 创建时间原样返回。托管三项全空返回 unverified，完整且合法才返回 verified 元数据；部分字段缺失、非法时间、精度丢失、跨链或非递增结果均拒绝。verified 只是已存元数据状态，不授权签名/归集，也不重新验证私钥控制权。查询只返回运行所需字段，导入来源由独立对账器负责。
