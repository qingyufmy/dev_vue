## 证据限制与语义

旧 server/routes/ai/account-performance.js 的 saveAccountPerformanceChunk 使用 payload.account.currency 或 context.account_currency，并在重复键时更新旧记录币种。因此这些表不是不可变的币种历史，不能据其当前值证明全部历史币种一直相同。审查产物明确 historicalCurrencyProven=false。

冻结源结构中平台列位于 bridge_v3_terminal_sessions，归属历史本身没有平台列。当前终端证据可支持当前实体候选；终端会话记录不等于逐归属区间的历史平台证据，historicalPlatformProven保持false。

第一轮复核区分公共实体的当前属性与历史金额/区间属性：当前币种不能反向填充未知的历史币种；已有业绩币种应跟随原记录保留。第二轮复核数据覆盖与来源可变性：不能将21日记录与3汇总简单相加为24段覆盖，也不能因没有发现冲突就声称274段历史已证明。脚本按归属ID去重并核对原账户ID。

## 后续约束

历史平台/币种审查尚不能据此关闭。下一步应区分实体当前元数据的迁移与历史财务/交易证据的迁移，对不可恢复的历史值保持未知并保留原始来源，禁止以当前绑定填空或跨币种聚合。现有账户波次草案仍不可执行；本批新增代码也使其旧工具集合需要在正式执行前重新冻结。历史时区、权限投影、真实业务回填及全域自动升级继续推进。
