# 同库升级第十四批：归属与授权 writer

归属 writer 已接入同库事务框架。每条旧归属产生一个区间、一个稳定 ID map 和逐源回执；完整历史先计算最终授权，再分页。只有被选中的区间携带该用户/账户的最终授权投影，先写区间，再写引用它的授权，满足组合外键。

## 两轮复核

第一轮（授权语义）：旧用户较早的区间不产生临时授权；再次取得账户的用户只保留最近或开放区间对应投影。已撤销的用户保留撤销时间。零长度区间作为历史证据保留，不覆盖同用户的开放授权。要求调用方提供完整冻结源 ID 集合，禁止分页后分别计算“最近归属”。

第二轮（数据与恢复）：账户与归属 writer 共享固定白名单的精确行存储器，仍然只 INSERT 或核对一致内容，不覆盖冲突行。逻辑引用不含临时表名；输入修改即使重算公开 hash 也在 SQL 前拒绝。账户 writer 的 schema 配置摘要保持原值，但抽取实现改变了执行文件，本批已重新跑真实组合演练，不能直接沿用上一批工具哈希证明当前实现。
