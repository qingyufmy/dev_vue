# 同库升级第三十六批：时段配置内容冻结

核对确认subscription_schedules.revision同时承担next_due游标推进，不能用它作为纯配置版本。新增subscriptionWindowFingerprint，以校验后的时区和窗口JSON内容计算SHA256；JSON键顺序和空白不影响摘要，调度游标、运行revision和时钟观测不参与。复用已有不可变推理快照存储，不为同一内容额外维护与游标混用的计数器，也不修改已执行SQL。

TraderWindowGuard返回允许时的配置摘要。Worker在准备前读取，将subscriptionWindowHash写入TraderInputSnapshot，首次/重试模型调用和返回后比对。beginTrader在同一事务读取当前配置并核对快照摘要，配置已变时结束queued任务。completeTrader在已有任务fencing校验后，读取持久化输入快照，核对payload_sha256及配置摘要，并检查当前窗口。缺少历史摘要或快照内容不可信为trader_schedule_unproven，配置变化为trader_schedule_changed；使用已有stale状态保存模型结果，不生成新的有效proposed决策。
