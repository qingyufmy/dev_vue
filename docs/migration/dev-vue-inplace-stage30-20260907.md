# 同库升级第三十批：排队分析和重试复查窗口

AnalysisWorker 新增必需的 AnalysisWindowGuard 端口，生产入口接入 MysqlAnalysisWindowGuard。scheduled任务在准备前、每次模型调用前（包括重试）按实际当前时间重新读取原行情账户对应的有效订阅及窗口。查询约束用户、账户、策略及版本、品种、active/analysis_enabled和当前owner；未找到对应订阅或丢失行情账户来源时拒绝。不会换一个账户继续处理冻结任务。

窗口时钟来自既有带归属/终端来源核对的账户快照。禁用窗口不读取时钟，窗外signals_only继续允许分析；模型准备耗时和重试跨边界时不再调用模型。准备前失败使用已有failQueuedAnalysis；运行中的窗口拒绝使用已有带fencing的失败状态，不进行模型重试。manual/event任务不套用自动订阅窗口政策，其已有权限检查保留。
