# 阶段 168：学习域迁移控制记录核验及只读探针准备

新增 verifyLearningMigrationControl，在最终业务对账的同一新事务快照中读取批次、逐行回执、检查点和 ID map。对照冻结 pipeline 核对完整记录集合及各字段：请求摘要、流、序号、行数、来源 PK/摘要、转换摘要、目标引用、最终游标和处理总数。缺失、多余、重复或任意字段改动均不能通过。

映射查询覆盖当前逻辑来源/源表，以及当前 run 创建的记录，防止当前 run 的跨域多余映射漏检。复用以前 run 的合法相同映射仍可按内容核对，不要求 created_run_id 被改写。课程媒体自增 ID 继续由 source archive 与三表审核核对。

课程、进度两个应用入口均已接入该检查；只有控制记录和业务数据同时通过才返回 verified。空集合也必须保留正确的零行检查点，不以没有业务行跳过迁移控制状态。
