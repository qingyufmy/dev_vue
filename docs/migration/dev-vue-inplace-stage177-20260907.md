## 尚未证明与下一步

1. 级别 6 跳过 redo，以上只能证明冻结基线及导出到干净实例的对账通过，不能排除基线后未被其他证据记录的已提交变化。不得用“导出成功”代替完整提交语义证明。
2. 自增最高水位尚未验收；需从故障前结构/备份/控制证据提取并与恢复后计数核对，避免复用曾经分配后删除的 ID。未记录的最高水位不得猜测为 MAX(id)+1。
3. 继续检查对象目录、约束行为、新增控制记录的业务不变量，以及密钥/对象存储等外部依赖；数据行一致不代表应用权限和文件可用性验收完成。
