# 阶段 145：管理员系统配置页面

/system从占位页替换为SystemSettingsView。59个已分类配置项使用中文分组和标签，通过新GET/PUT读取实际值、保持版本并进入已有请求恢复控制器。页面不创建或填充缺失配置，尚无迁移记录明确显示暂不可编辑。

布尔/枚举使用共享Select，整数使用文本Input保留精度并校验已冻结范围。凭据仅显示配置状态、不展示内容；尚需业务语义校验的配置仅供查看。保存后确认结果再读取新版本；未知结果保留原请求、显示确认按钮、禁用配置切换，并通过路由守卫阻止离开。

未保存修改可撤销。beforeunload为未保存/未知状态触发浏览器原生离开提示；用户强制关闭或刷新仍会丢失内存请求，此限制没有被声明为跨刷新恢复。切换用户时清除读取数据并拒绝跨用户恢复。
