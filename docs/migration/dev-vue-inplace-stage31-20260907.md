# 同库升级第三十一批：交易员分发窗口

completeAnalysis 的自动分发查询现包含订阅时段行及当前owner约束；在创建每个交易员任务前，在同一业务事务判断当前窗口。窗外signals_only只允许市场分析，不生成账户交易员任务。没有时段行的订阅不参与分发，未启用窗口沿用允许状态。分析结果仍正常保存，单个关闭窗口不撤销有效分析结果。

新增交易域 readTransactionAccountClock，通过现有事务连接读取时钟，核对账户/用户有效状态、当前所有权区间与revision、唯一终端绑定、终端用户/平台、投影revision及来源、未断开会话epoch。无来源或多行时返回null；不将当前裸时区列视作可信时钟。读取使用FOR SHARE，调用期间没有外部服务或模型I/O。它返回缓存时钟证据，不代表Bridge在线、账户具备交易权限或风险检查完成。

4项新增测试加17项窗口/推理回归共21项通过；服务端类型检查和构建通过。实际repository方法的模拟事务测试确认：窗口不能确认时仍提交分析，但不插入ai_trader_runs，也不创建trader.requested事件。查询来源与窗口边界的行为测试通过。新增SQL尚未在真实V4数据库执行验证；当前dev_vue仍处于旧表承接阶段。本批未运行角色、未执行DDL/DML、未调用模型。

剩余：交易员自身排队/重试及最终执行检查、窗口revision绑定、全域业务转换/对账和完整自动升级。现有执行链路未因此被宣称已完成时段限制，迁移候选的运行接入门槛继续保留。
