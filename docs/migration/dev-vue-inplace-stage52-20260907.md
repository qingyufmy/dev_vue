## 实现

- 分析配置新增 `ema34_evidence: { version: 1, timeframe: "M1" }`，严格版本及周期检查；未配置的已有版本保持原行为。不会把旧 `shadow` 策略自动提升为新执行策略。
- 同账户、同品种、同周期一次读取 `max(展示数量, 61)` 根历史，模型的 candles 字段仍保留配置的展示数量。第 61 根用于容纳尚未收盘尾柱；指标冻结原始输入、revision、账户、品种、周期、计算参考时刻。
- 指标独有周期可以单独读取，不添加到 candles 展示周期。冻结的 input_bars 是额外证据，会增加快照和模型输入体积；不声称整个输入只有展示窗口大小。
- AnalysisContextBuilder 将同一 capturedAt 传入指标计算。数据必须使用交易仓库的 UTC 时间；UTC+3 展示默认值不参与计算或历史回填。
- 连续性策略 `contiguous_only/v1`：任何非连续时间间隔均视为未解决缺口；不会猜测周末/节假日交易日历。缺口、陈旧、未来柱及历史不足时返回不可用证据，不提供有效 EMA 值，也不新增交易硬拦截。
