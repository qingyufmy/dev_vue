本轮修正了“system_config 全表都应搬为全局 system_settings”的潜在错误：用户偏好独立设计，疑似旧键先保留并核实，其他配置逐键确定类型。原始八字段仍需全量承接。七项相关测试通过，验证用户后缀、未知键默认受限、旧键不自动删除、禁止原 value 输入及重复身份拒绝。
