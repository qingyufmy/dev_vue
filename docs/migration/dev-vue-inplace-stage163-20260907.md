# 阶段 163：课程、课时与媒体引用完整转换及写入器

课程原始 26 字段全部进入 provenance。主行映射到 learning_courses，每个旧课程生成一个 learning_lessons；公开 episode_id 与内部课程/课时 ID 分开。六种非空媒体定位符逐字保留到 learning_media_references；NULL 和空串仍在原始存证中，不伪造可用媒体。旧流媒体标志和四种派生计数只保存在来源存证，不作为新系统可用性或资源数量事实。

learning-course-import/v1 依据绑定完整来源集合、sourceSnapshotId、逐行摘要、创建/更新时间和四项语义审查证据。时间没有明确依据不转换；测试中的 UTC+8 是合成测试依据，不是旧库历史时区结论。课程时长使用精确毫秒文本，访问权限、状态和 NULL 原样保留。输出课时映射可直接提供给阶段 162 的进度转换。

mysql-learning-course-writer.mjs 在调用者事务内锁定旧课程全行，再按课程、课时、媒体顺序写入。已有目标必须逐字段相同；额外媒体、目标冲突或来源变化均拒绝，不覆盖或删除。媒体通过 lesson_id/source_kind 唯一键回读真实 ID，避免依赖可能失真的数值 insertId。verifyOnly 不补写；未知插入结果不自动重放。

## 验证与定向复核

6 个测试文件共 22 项通过，包括课程转换、课程 writer、进度转换、进度 writer、字段合同及精确时长。新增 writer 测试覆盖父子写入、超过 JavaScript 安全整数的媒体 ID、重复执行、只读核验、来源变化、调用者篡改、目标冲突、额外媒体和插入确认丢失。

本次是源码、纯转换及 Mock SQL 验证，未执行真实课程回填。writer 不自行提交事务；父行插入后子行失败必须由批次调用者回滚。正式批次还需登记 run、持久化 provenance/映射/receipt/checkpoint，并由独立对账确认提交结果。媒体定位符保留不证明外部文件可访问。
