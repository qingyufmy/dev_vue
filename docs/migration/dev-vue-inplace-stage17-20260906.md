# 同库升级第十七批：真实归属事实交叉核对

当前 dev_vue 真实只读核对通过：4条账户、274段历史归属、3个当前绑定和3段开放归属，合并后对应3个有当前事实的公共实体、4个历史用户/账户组合。三个绑定均与各自唯一开放区间的原用户、原账户ID及身份一致，没有多个当前所有者或缺失用户。

## 本批发现与修正

首轮检查把一个当前绑定账户的 observe_status=switched 当成非活动异常。复核旧 server/routes/ai/risk-state.js 的 activeDifferent 分支确认：同一用户切换账户时，会将原账户标为 switched，并调整旧订阅/调度相关状态；这个标记不是所有权撤销。该记录的当前绑定与开放归属本身一致，review_status=approved、is_deleted=0、anomaly_code=NULL。

检查器因此将 switched 单独记为 legacy_single_account_switched 说明项，不据此撤销归属；其它非active状态仍需复核。转换器继续保留原观察状态；本批不恢复任何订阅、调度、风控或交易许可，也不把归属一致当作可交易。

首轮证据 [初始审查](dev-vue-account-ownership-review-20260906.json) 保留；修正语义后的权威证据为 [v2审查](dev-vue-account-ownership-review-v2-20260906.json)。两个报告的源事实摘要相同，变化来自审查规则解释，不是数据库修复。再次执行 --verify 后完整稳定摘要一致。

## 复核与验证

第一轮限定当前归属事实：保留历史用户，检查两个方向的绑定/开放区间缺失，合并后检测多所有者，核对精确旧账户ID。第二轮检查状态语义和证据边界：旧单账户连接选择不等于账户所有权，多账户V4迁移不应因switched丢失归属；缺少历史时间依据时不输出UTC日期或交易资格结论。

5项新增测试通过：历史所有者保留、输入顺序稳定、双向缺失、多开放所有者、用户/绑定不一致、已删除账户以及switched语义。脚本为 `node scripts/review-dev-vue-account-ownership.mjs --read-only|--verify`。审查绑定v2回填结构身份，报告仅保存摘要、计数与脱敏定位，不输出登录号。
