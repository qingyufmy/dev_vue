## 2. 回放元数据问题与修复结论

### 2.1 原错误链

旧历史回放快照没有稳定的 `source_id`。来源身份缺失后，安全校验按以下链路逐级降级：

```text
source_id=null
  -> sourceIdentityReliable=false
  -> structure_time_key_reliable=false
  -> topology_input_complete=false
  -> data_complete=false
  -> local_structure_usable=false
```

因此，旧报告中“历史正常负载 M15/M5 缠论长期不可用”的结论不成立。它证明的是：来源身份不可信时，系统安全门会拒绝使用 Chan；它不能证明生产行情或当前代码计算出的 Chan 结构失效。

### 2.2 修复范围

历史回放生成器现在依据冻结行情身份产生稳定、可复现且为正的合成 `source_id`，同时传递 `source_key` 和 `source_identity_mode=historical_replay_synthetic` 到 Chan 数据质量和策略来源。相同数据集得到相同身份，不同数据集得到不同身份；没有修改生产 Chan 安全门，也没有把历史合成身份伪装成生产终端身份。

修复增加了回归测试，覆盖稳定性、不同数据集区分、降级数据集、正安全整数以及 data quality/policy source 传播。

### 2.3 修复后的八个检查点能力

以下是同一冻结数据、同一八个检查点的直接能力复核；`x/8` 表示该能力在八个检查点中可用的数量：

| 周期 | 修复后能力结果 |
|---|---|
| M5 | `local` 8/8；`segment` 7/8；`center/entry/divergence` 6/8 |
| M15 | `local/segment` 8/8；`center/entry/divergence` 5/8 |
| H1 | `local` 8/8；`segment/center` 7/8；`entry/divergence` 0/8 |
| H4 | `local/segment` 8/8；`center/entry/divergence` 0/8 |

这组结果说明：原先“全部 `local_structure_usable=false`”主要是回放来源元数据缺陷，不是缠论计算在所有周期都失效。不同能力仍然可能在某个检查点不可用，模型必须尊重能力状态，不能把能力可用等同于买卖点已成立。

## 7. 两份候选提示词的修改内容

### 7.1 A：H1 主判 / H4 严格降级

- H1 是唯一常态宏观方向来源；只有 H1 不明确时才启用 H4；H1 明确时 H4 不投票、不否决；
- M15 只承担机会背景和反向事件否决，不恢复旧版多项计票，也不能夺取 H1 主判权；
- M5/M1 只读取当前已闭合、仍有效的系统新鲜客观触发；不从原始 K 线重算；
- M1 负责下一时机和 EMA34 最终过滤，前置未通过时不提前判定 M1 失败；
- 结构保护只读取最新触发对象的系统失效位/保护锚点；正式净风险收益至少 1.5；
- 同向同事件去重 30 分钟，最大观察 240 分钟；H1 主判/ H4 降级风险分别为 1%/0.5%；
- 只复用通用 JSON 字段，不新增 A 专属输出字段。

### 7.2 B：M15 主判 / H1 严格降级

- M15 是唯一常态宏观方向来源；只有 M15 不明确时才启用 H1；M15 明确时 H1 不投票、不否决；
- 不再把旧版“六项至少两项”作为模型必须补足的硬门槛；M15 Chan 只读取系统能力和当前结构，不能由模型重算；
- 当前 M5/M1 新客观触发、系统 Chan 局部反转或严格回收可以作为触发来源，但不能脱离 M15/H1 宏观方向自行翻转；
- M15 当前反向事件能够明确确认时否决；未知不能写成无冲突；
- 同向同结构事件去重 15 分钟，最大观察 240 分钟；M15 主判/ H1 降级风险分别为 1%/0.5%；
- 回测选出的 RR=1.0 明确标为“仅研究实验且样本外失败”，正式执行门槛保持净 RR≥1.5；
- 只复用通用 JSON 字段，不新增 B 专属输出字段。

## 8. 为什么不能据此继续调到“通过”

A 的 RR1.5 训练高收益、B 的训练高收益和两者的样本外回落说明，继续在这一段行情上反复搜索触发组合、去重窗口、ATR 下限、持有时间和 RR，容易把偶然路径当成规律。A 的 RR1.0 频率实验虽然三个分段都为正并刚好超过月利润门槛，但它同样来自 2,880 组搜索且尚未经历真正未参与选参的新月份。White 的 Reality Check 以及 Bailey 等关于回测过拟合的研究都指出，反复试验会提高样本内最优而降低样本外可信度。[White 2000](https://onlinelibrary.wiley.com/doi/pdf/10.1111/1468-0262.00152)；[Bailey 等](https://papers.ssrn.com/sol3/papers.cfm?abstract_id=2308659)

缠论结构本身用于描述已完成的结构、背驰和买卖点，不等于每个微小波动都应该成交；买卖点还需要当前触发、保护、空间和执行条件共同成立。[缠中说禅第41课](https://blog.sina.com.cn/s/blog_486e105c010009i4.html)

因此，本轮把“频率达到”与“收益达到”分开报告，并以验证/留出为否决依据。当前正确动作是保留研究候选和可复现回放，补充更多独立月份和模型一致性证据，而不是继续对同一窗口放宽条件。

## 9. 两轮复审、调整与剩余风险

### 9.1 第一轮复审：策略逻辑

核对范围：需求覆盖、周期职责、系统数据权威、最小改动和是否设计过度。

复审发现并完成的调整：

- 将 A 固定为 H1 主判、H4 仅严格降级；将 B 固定为 M15 主判、H1 仅严格降级；
- 删除两套候选中会把下游未检查项当失败、把旧背景当当前方向或把 M5/M1 投票升级为宏观方向的表述；
- 明确系统 Chan 唯一权威，系统已有指标和客观布尔值只读取，不要求模型写计算公式；
- 将 M15 六项计票从 B 的旧式硬门槛中移除，改为系统当前方向、机会背景和反向否决的职责；
- 将 A 的 M15 限定为机会/反向否决，不让它取代 H1 主判；
- 统一通用输出字段和字段一致性说明，不新增策略专属 schema，不在服务端增加策略硬限制；
- 把 B 的 RR=1.0 明确标为样本外失败的研究对照，正式门槛仍为净 RR≥1.5；
- 把研究候选和“不得直接上线/替换生产”写在两份提示词开头。

第一轮结论：策略职责和数据边界已覆盖当前需求；仍不能由逻辑文本证明收益或每个买卖点都能成交。

### 9.2 第二轮复审：执行、数据与统计

基于第一轮调整后的版本，重新核对兼容性、数据缺口、并发/去重、时间语义、异常恢复、统计口径和回滚边界：

- 检查点严格按时间排序，未来 M1 只进入成交和结果，不进入信号；
- 训练选参与验证/留出评价分离，部分交易日不被伪装成完整日；
- 两个账户独立计算余额、持仓占用、风险和曲线，未混用账户结果；
- 同一活动订单/持仓、去重窗口、240 分钟超时和同一根 K 线止损优先均保持确定性；
- 缺少系统布尔字段、来源身份、闭合时间、结构保护或风险收益时，不把未知当通过；下游未检查不列为失败；
- 未改变生产安全门、服务端策略权威边界、数据库、虚拟机或下单链路；候选提示词可删除/回退，不影响当前生产提示词；
- 验收使用净利润和样本外结果，不以训练集高收益替代正式通过。

第二轮结论：回放和账户口径可复现，但 A/B 的验证、留出和月度利润均不足，不能发布。若要继续研究，必须引入未参与调参的新月份/品种或预先冻结的新测试区间，并重新记录版本和来源身份。

### 9.3 剩余风险与未验证项

- 当前证据主要来自一个 XAUUSD 约 30 日窗口；不足以推断跨月份、跨行情状态或跨品种稳定性；
- DeepSeek 逐点模型复放只有八个代表点；A 为 7 次成功、1 次上游失败且零订单，B 为 8 次成功且零订单，不能替代 7,447 个检查点的真实模型逐轮调用；
- v2 的频率提升依赖更短周期触发，验证和留出反转说明信号数量增加没有自动转化为利润；
- 生产模型延迟、请求体大小、服务商失败重试和快照新鲜度仍需单独影子验证；
- H4/H1 降级在本次样本的实际触发次数有限，不能据少量样本评价备判覆盖率；
- 来源身份修复已覆盖历史回放生成器和回归测试，但仍需在真实自动分析快照中核对来源身份、时间键和能力状态；
- 本轮没有部署、启用候选提示词或发送真实订单。

## 10. 最终验收决定

两套策略的频率研究结果可以作为后续实验起点。A 的 RR1.5 主候选为 +2,356.58，B 为 +1,877.66，且两者验证/留出均为负。A 的 RR1.0 频率实验得到 +3,048.38、日均 31.48 笔且三个分段为正，按离线数值门槛初步通过，但尚未通过独立新月份和正常模型下单验证；两份新提示词在八个正常负载检查点均为零订单。因此：

**A：离线代理存在一个初步达标组合，但端到端不通过；B：不通过；两份提示词仅保留为研究候选，不得上线。**

## 11. 策略排序与下一步主优化方向

综合利润、PF、回撤、风险收益质量和模型表现，排序为：

1. **A：H1 主判 → H4 严格降级**，作为后续主优化方向；
2. **B：M15 主判 → H1 严格降级**，只保留为固定对照组，不再优先放宽。

A 更优的理由不是它已经可以上线，而是它同时拥有更高的 RR1.5 滚动收益（+2,356.58 对 +1,877.66）、更低的最大回撤（21.0701% 对 23.7252%）、更好的 PF（1.113 对 1.070），并且唯一出现了一个三个时间分段均为正、滚动数值刚好达标的 RR1.0 实验组合。B 的高频依赖 RR1.0，验证和留出仍为负，继续放宽更可能放大噪声。

下一轮只重点优化 A，并冻结 B 作为对照。顺序应为：

1. 先由系统策略中立地产出并注入本轮离线工具所用的 M1 EMA 恢复/动量与 M5 突破/回踩恢复的已闭合、新鲜、方向、事件键和失效状态；提示词只读取这些字段，不复制计算公式；
2. 用同一冻结快照验证系统字段与离线确定性特征逐点一致，再运行 DeepSeek 影子复放，目标是消除“离线有触发、模型因字段缺失而观望”的落差；
3. 预先冻结未参与本轮 2,880 组搜索的新月份，分别复验 RR1.5 主候选与 RR1.0 实验；只有新月份也满足净利润、频率、最大回撤和模型下单一致性，才讨论升级；
4. 将日均 31.48 笔压回用户期望的 5–10 笔附近，优先使用事件新鲜度、独立事件键和系统结构质量去重，不提高风险、不扩大杠杆，也不继续降低 RR；
5. 同时测量流式推理成功率和延迟。当前 A 成功调用中位约 96.5 秒，B 约 144.5 秒，必须证明 5 分钟调度下不会形成积压后再考虑上线。
