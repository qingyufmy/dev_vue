# 第三轮全面审计报告 — 2026-07-05 v3

## 审计方法
5 个并行 explore agent 分别覆盖：服务端死代码、前端、数据库、依赖测试、安全

---

## CRITICAL — 必须修复

### 1. ai/index.js 缺少 3 个 re-export（smart-close 功能完全失效）
`bridge-ws.js:1366,1380,1389,1427,1632,1633` 调用 `ai.getCloseConfig()`、`ai.saveCloseConfig()`、`ai.getCloseSignalTickets()`，但 `ai/index.js:68-74` 的导出列表中缺少这 3 个函数。运行时 TypeError 被外层 catch 吞掉，smart-close 功能完全静默失效。
**文件**: `server/routes/ai/index.js:68-74`
**修复**: 添加 `getCloseConfig, saveCloseConfig, getCloseSignalTickets` 到 re-export

---

## HIGH — 应尽快修复

### 2. PUT /posts 缺少 sanitizeContentHtml（存储型 XSS）
`POST /posts` 和 `POST /post-replies` 都调用了 `sanitizeContentHtml()`，但 `PUT /posts`（编辑帖子，line 241）直接将用户输入的 `content` 存入 DB，绕过了 XSS 过滤。
**文件**: `server/routes/posts.js:241`
**修复**: 对 `content` 调用 `sanitizeContentHtml(content)`

### 3. sendToBrowsers().catch() 对非 Promise 调用
`sendToBrowsers` 是同步函数（返回 undefined），`.catch()` 会抛 TypeError。被外层 catch 吞掉，但 pending_filled 通知静默丢失。
**文件**: `server/routes/ai/scheduler.js:1095`
**修复**: 移除 `.catch(() => {})`

### 4. parseDate ReferenceError
`renderPendingSignalInfo()` 中调用 `parseDate`，但该函数只在 `renderPendingOrders()` 内部定义（作用域外）。挂单有 entry_method=limit/stop 时触发 ReferenceError。
**文件**: `public/ai/app.js:2687`
**修复**: 将 parseDate 提取为模块级函数

---

## MEDIUM — 建议修复

### 5. bridge-ws.js:1940 catch-all 泄露 err.message
`handleBrowserCommand` 末尾 catch 直接返回 `err.message`，可能包含 SQL 表名、文件路径。
**文件**: `server/bridge-ws.js:1940`
**修复**: 替换为通用错误消息

### 6. ai/config.js:657 executeOrderCore 泄露 err.message
`result = { status: 'error', message: err.message }` 可能暴露 MT5/桥接内部错误。
**文件**: `server/routes/ai/config.js:657`
**修复**: 替换为通用错误消息

### 7. video.js SSE /stream 端点无认证无连接限制
未认证客户端可开无限 SSE 连接，每个保持 setInterval，耗尽服务器资源。
**文件**: `server/routes/video.js:352-357`
**修复**: 添加 authMiddleware + 连接数限制

### 8. index.html 53 行注释掉的 smart-close HTML
`public/ai/index.html:524-576` 有完整 smart-close 配置面板的注释代码。
**文件**: `public/ai/index.html:524-576`
**修复**: 删除或保留为功能预留

### 9. llm.js:76 硬编码 OpenAI URL
`https://api.openai.com` 应提取为 config.js 常量。
**文件**: `server/routes/ai/llm.js:76`
