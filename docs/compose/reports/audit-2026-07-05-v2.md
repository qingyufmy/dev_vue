## HIGH — 应尽快修复

### 1. `ui_configs` 死表 — 从未被 SELECT/INSERT/UPDATE
`db.js` initDB() 中创建了 `ui_configs` 表，但整个代码库中唯一引用是 `admin.js:301` 的 DELETE（删除用户时连带清除）。从未被写入或读取，是完全死表。
**文件**: `server/db.js:490`
**修复**: 新建迁移 DROP TABLE ui_configs，并删除 `db.js` 中的 CREATE TABLE 语句

### 2. `trades` 表死列残留
migration 023 尝试 DROP `trades.description` 和 `trades.image_url`，但 `db.js` 的 `CREATE TABLE IF NOT EXISTS` 中仍保留这两列。每次服务器重启都会重新创建已删除的列。
**文件**: `server/db.js:264-273`
**修复**: 从 `db.js` CREATE TABLE 中删除 `description`、`image_url`、`pnl` 列（migration 023 已处理 DROP）

### 3. `users.current_view` 列从未使用
定义在 `db.js:144`，整个代码库中无任何 SQL 引用此列。
**文件**: `server/db.js:144`
**修复**: 新建迁移 DROP COLUMN，从 CREATE TABLE 中删除

### 4. 39 个空 catch 块吞掉错误
`bridge-ws.js` 有 13+ 个空 catch，`migrations.js` 有 10+，`video.js` 4 个，`posts.js` 2 个，`admin.js` 1 个。生产环境出错时零日志，无法排查。
**关键位置**:
- `bridge-ws.js:69,193,257,271,370,371,491,524,1120,1126,1339,1356,1554`
- `server/routes/ai/llm.js:88`
- `server/routes/ai/strategy.js:83`
- `server/routes/video.js:139,141,253,302`
- `server/routes/posts.js:432,445`
**修复**: 至少加 `console.error('[模块名]', e)` 或 `console.warn`

### 5. WebSocket 错误信息泄露内部细节
`bridge-ws.js:1442,1458,1479` 将 `e.message` 直接拼入 WS 响应：`'获取挂单列表失败: ' + e.message`。内部异常可能包含 SQL 错误、文件路径等敏感信息。
**文件**: `server/bridge-ws.js:1442,1458,1479`
**修复**: 替换为通用错误消息，保留 console.error 详情

### 6. 12 个路由文件零测试覆盖
auth.js、admin.js、payment.js、user.js、posts.js、comments.js、courses.js、trades.js、video.js、feedback.js、config.js、sentiment.js 均无测试。其中 auth.js、admin.js、payment.js 涉及安全，风险最高。
**影响**: 安全关键路径无回归保护

**文件**: `server/routes/ai/strategy.js:61`, `server/routes/ai/scheduler.js:1391`

### 11. `loadCloseSignalTickets()` 死函数

### 12. ~115 行注释掉的 smart-close 代码

### 13. 硬编码桥接下载 URL

**文件**: `public/ai/app.js:755-757`
**修复**: 删除或简化函数

### 16. `sentiment.js` 竞态条件
`_fetching` 布尔值非原子操作，两个并发 POST 可能同时读到 `false` 并触发重复 fetch。`try/finally` 防止 flag 卡住，但不防重复。
**文件**: `server/routes/sentiment.js:10,29,39`
**修复**: 用 Promise 锁或 simple locking pattern

### 17. `referrals/track` GET 返回硬编码零值
`user.js:259` 返回 `'WSS' + String(req.user?.id || 0)`，因无 auth 中间件，`req.user` 永远 undefined，结果永远是 `'WSS0000'`。
**文件**: `server/routes/user.js:257-260`
**修复**: 添加 authMiddleware 或删除此端点
