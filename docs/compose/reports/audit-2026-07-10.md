## CRITICAL — 必须立即修复

### C1. `courses.js:110-111` — 未定义变量 `d` 导致 ReferenceError
**文件**: `server/routes/courses.js:110-111`
**问题**: `/bilibili-info/:bvid` 端点解构结果为 `bi`，但第 110-111 行引用 `d.title` 和 `d.duration`。`d` 未定义，每次调用必崩。
**修复**: `d.title` → `bi.title`，`d.duration` → `bi.duration`

### C2. `saveGlobalAutoConfig` 引用已删除列 — 运行时 MySQL 错误
**文件**: `server/routes/ai/config.js:200-217`
**问题**: 函数写入 `symbols` 和 `system_prompt` 列，但 migration 031 已从 `global_auto_config` 删除这两列。调用时 MySQL 报 `Unknown column` 错误。
**触发**: `bridge-ws.js:1263` 的 `admin_save_auto_global_config` handler
**修复**: 移除 `symbols` 和 `system_prompt` 的写入（这两列已迁移到 `auto_prompt_types`）

### C3. `getAutoConfig` 读取已删除列 — selected_symbols 永远为空
**文件**: `server/routes/ai/config.js:165-188`
**问题**: 第 180 行读取 `row.symbols`，但 `auto_scheduler.symbols` 已被 migration 031 删除。`row.symbols` 永远 `undefined`，`selected_symbols` 永远 `[]`。
**影响**: 通过 `getAutoConfig` 获取的配置中用户选中的品种列表始终为空
**修复**: 从 `auto_scheduler` 读取时不再尝试解析 `symbols` 列

### C4. `reconcileAutoSchedulers` 查询缺少 `user_symbols` 列 — 交集逻辑失效
**文件**: `server/routes/ai/scheduler.js:433-455`
**问题**: SQL SELECT 只查 `apt.symbols_json`（重复两遍），未查 `user_symbols`。第 452 行 `row.user_symbols` 永远 `undefined`，fallback 为 `'[]'`，交集结果永远为空。**所有调度器键都会被 reconciliation 停止。**
**影响**: 统一调度器的 reconciliation 逻辑无法正确维护调度状态
**修复**: 要么在 SELECT 中加入用户品种列，要么移除不存在的交集逻辑

**修复**: 删除 bridge-ws.js 的本地副本，导入 `utcToMt5Time`

### H5. admin 资源上传路径穿越风险
**文件**: `server/routes/admin.js:557`
**问题**: `file.originalname` 仅剥离首层目录前缀，未过滤 `../`。恶意文件名可逃逸目标目录。

### H7. `_verifyFailedAttempts` 无定期清理 — 内存无限增长
**文件**: `server/routes/auth.js:18`
**问题**: 验证码暴力破解追踪 Map 无 TTL 清理。攻击者枚举大量手机号/邮箱时内存持续增长。
**修复**: 添加 15 分钟定期清理（类似 captcha.js 的模式）

### H8. CSP 使用 `unsafe-inline` 和 `unsafe-eval`
**文件**: `server/index.js:67`
**问题**: 显著削弱 XSS 防护。当前因 inline script/style 和 eval 需要而保留。
**修复**: 逐步内联脚本外置，收紧 CSP

### H9. 缺少标准安全头
**文件**: `server/index.js`
**缺失**: `X-Content-Type-Options: nosniff`、`X-Frame-Options`、`Strict-Transport-Security`、`Referrer-Policy`、移除 `X-Powered-By`
**修复**: 通过 helmet 或手动中间件添加
