# M15/H1/M5 目标策略提示词 v2.1 说明

完整提示词以 [dao-cheng-v2.1-system-prompt.md](./dao-cheng-v2.1-system-prompt.md) 为准。它属于目标策略数据，不是系统公共提示常量；界面中的“启用 EMA34 入场过滤”开关开启后直接正式生效。

## 趋势仲裁

- 先只判断 M15：`up`、`down`、`unclear` 或 `unavailable` 四者必须且只能选择一个。
- `unclear` 表示 M15 数据完整，但相互冲突的有效证据使方向无法唯一确定。
- `unavailable` 表示 M15 数据、结构或质量不足，必须停止新入场；不得启用 H1 绕过。
- 只有 M15=`unclear` 时才判断 H1。M15 已是 `up/down` 时，H1 必须标记为 skipped，不能参与确认、共振、评分或记忆。
- H1 接管后，最终方向来自 H1；M15 后续只用于寻找同向机会，不得重新投票改变方向。

## 机会确认与触发

- 方向确定后，M15 必须给出至少两项互相独立、且与最终方向一致的机会确认；否则保持观望。
- M5 只负责最终入场时机，必须给出至少一项可核验触发；M5 不参与趋势方向投票。
- 任意上游阶段未通过时，不得以 S 级、强信号、高置信度或其他评分绕过。
- EMA34 由系统固定代码计算并执行。它可作为短线位置、斜率、距离、持续性和最近穿越的行情证据，但只过滤新入场，不计入 M15 确认或 M5 触发数量，也不用于退出持仓或撤销已有挂单。

## 结构化输出

无需输出额外规则配置或工作流轨迹。证据引用必须对应当前输入中可核验的行情或结构字段。
