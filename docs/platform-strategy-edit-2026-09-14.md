# 管理员编辑平台策略

范围：交易端对管理员显示编辑入口，管理端编辑最新版本的提示词与配置，保存为新的草稿版本。沿用管理员会话、CSRF、版本号和幂等回执，不增加数据表或交易端写权限。

第一轮复核（需求与复杂度）：复用现有策略版本表与发布流程。平台策略编辑集中在管理端，交易端直接链接到选定策略。个人策略编辑保持现状。

第二轮复核（权限与一致性）：HTTP 与事务均校验管理员；事务锁定平台策略后分配版本号；检查 revision；重复请求返回回执；权限撤销后回放仍拒绝。保存不替换 active_version_id，不启动分析或交易。不通过真实策略写入做界面验证。

验证：服务器构建、管理端及交易端类型检查、生成合同一致性、平台编辑与发布定向测试。浏览器确认编辑入口及完整提示词表单。

限制：版本发布仍为独立操作；平台版本发布不自动重绑已有订阅。当前仓库存在大量前序改动，本次未单独推送。

## 当前页编辑与行情设置修订

用户明确要求不离开交易端。移除管理端跳转，复用当前编辑 Sheet；交易端已有版本 API 对平台目标委派到管理员写入服务，事务校验仍由管理员访问端口负责。普通用户仍不能修改平台策略。保存、发布、订阅绑定为分别明确的操作。

复核一：全部配置均进入版本 config；保留未编辑字段；关闭数据项不修改提示词。复核二：EMA 周期必须来自行情范围；调度与订阅显示均读取绑定版本间隔；保存草稿不影响当前版本，平台发布不擅自重绑其他用户订阅。旧版本和历史记录保留。无数据库迁移、无真实保存或交易测试。
