# Task 10 交付结果：前端信息架构与权限集成

## 结论

模型、策略、用户风控、管理员全局风控、执行对照、复盘与个人记忆已经进入统一 AI 工作台。页面文案明确标注“谁能修改什么”，凭据不在浏览器状态或旧推理配置表单中重复保存。

## 已实现

- **模型管理**：一个模型配置同时服务手动推理、自动推理、复盘和压缩；管理员维护共享用途与每日请求/Token 配额。
- **推理策略**：用户只能创建和执行自己的私有策略；管理员维护平台策略，并能看到其他用户策略的归属但仅可审计、不可代为编辑或执行。
- **风控中心（用户）**：显示用户值、平台范围、最终有效值和待生效状态；价格偏差可由用户在平台边界内配置。
- **全局风控（管理员）**：管理默认值、范围、锁定值、Kill Switch、恢复审批、规则 Shadow/Enforce 与功能灰度；强制规则禁止 Shadow。
- **手数说明**：AI 必须在平台建议手数最小值、最大值和步进内输出；页面同时展示 AI 建议、风险上限、最终下单手数和成交偏差，最终值不会高于 AI 建议与风控上限。
- **复盘与记忆**：用户修订并确认复盘，管理自己的记忆和个人灰度；明确提示管理员无法查看正文，以及付费配对会额外调用模型。
- **鉴权入口**：页面在早期重定向前接收 `?token=` 并落入本地会话，修复外部跳转无法进入工作台的问题。

## 响应式与可访问性验收

- 1280×720 桌面端检查策略、模型、风控、全局风控和复盘页面，无页面级横向溢出。
- 390×844 移动端修复 Grid 固有最小宽度，文档宽度与视口一致；导航保留独立横向滚动，不裁切主内容。

- 保留加载骨架、空状态、Reduced Motion 和可滚动数据表。
