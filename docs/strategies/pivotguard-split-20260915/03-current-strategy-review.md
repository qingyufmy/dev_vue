# 当前策略规则与评审

2026-09-15。当前配套版本：[行情分析 v2](01-market-analysis-prompt.md)、[AI 交易员 v5](02-ai-trader-prompt.md)。这是策略文档完善，不是线上配置修改或历史收益验证。`00-review-and-integration.md` 的 EA 阅读部分保留为来源；其中 v1 实施建议不作为当前策略要求。

## 本版已确认的原则

- 两个策略：行情分析负责公共市场依据；交易员负责具体账户的入场、完整退出、挂单和保护调整。
- 不做部分平仓。SL 和 TP 都允许上调或下调，不设置单向调整限制。
- EA 只作管理思路参考，不照搬固定点距、P 点必平、减半、3 秒越线或 50% 回撤。
- 不设计运行间隔、触发、队列或其他调度链路。
- 保留来源策略的 H1/H4、M15、M5、M1 入场层级和原风险上限，不以这次完善为由放松入场条件或增加新的数值门槛。

## 本次补齐

1. 分析输出提供明确方向和证据身份，避免公共分析使用无参照的“反向”影响不同方向持仓。
2. 交易员按具体动作判断需要哪些数据。Pivot 和峰值是辅助信息，缺少它们不阻断完整的结构判断。
3. 市价、回踩限价、突破挂单和止损限价各有采用依据；挂单不能绕过未完成的分析确认。
4. TP2 缺失时可检查真实 TP1；不得为了收益风险数字而跳过已确认阻挡或造远目标。
5. 分开处理“分析无新机会”“入场事件过期”“持仓逻辑失效”，不一律撤单或平仓。
6. 给出收紧 SL、放宽 SL、拉远 TP、拉近 TP 的判断依据。持仓原逻辑仍有效时可以放宽 SL；明确失效时完整退出。
7. 初始收益风险门槛约束新入场和挂单，不强迫已持仓交易为了原比值拒绝合理退出。
8. 明确同一对象的动作优先级及不变项保留，避免同轮平仓又改单、或空值覆盖已有保护。

## 第一轮评审：决策覆盖

采用文档逐项推演，未运行模型或终端。

| 情形 | 策略应如何判断 |
|---|---|
| H1 反转观察但 M15 尚未确认 | 不入场，不转 H4 绕过；已有仓位另行评估 |
| 候选有效但当前市价已离开允许区域 | 只考虑有明确依据的合法挂单，否则等待 |
| TP2 缺失、TP1 真实且收益风险达标 | 可按 TP1 作为完整目标，不强求 TP2 |
| 近端阻挡明确且没有通过依据，远目标比值更好 | 不只为比值跳选远目标 |
| 分析无新机会，旧挂单事件仍有效 | 独立检查后可保留 |
| 未成交挂单原事件已过期 | 取消旧挂单，不用新分析为旧事件续期 |
| 已成交持仓的原入场事件变旧 | 不因此平仓，检查持仓结构和保护 |
| 同向结构推进，形成更合适的近端保护 | 可收紧 SL，不要求先到 P 点 |
| 持仓逻辑有效，新结构支持外侧保护且风险通过 | 可放宽 SL，不因价格方向拒绝 |
| 原交易逻辑已经明确失效 | 完整退出，不靠继续放宽 SL 延长 |
| 阻挡确认突破，存在真实更远目标 | 可拉远 TP |
| 出现较近阻挡但尚不要求立即退出 | 可拉近 TP，已有仓位不强求原目标比值 |
| 新目标已被当前报价越过，意图立即退出 | 完整平仓，不挂无效 TP |
| 当前 SL/TP 与建议值相同 | 保持，不重复改单 |
| 同一对象有完整退出与调整保护两种理由 | 完整退出优先 |
| 仅缺少 Pivot 或峰值，结构证据完整 | 继续结构判断，不整体停用策略 |

## 第二轮评审：一致性与范围

- 对照用户要求：没有主动部分平仓；止损、止盈均可双向调整；没有调度设计。
- 对照来源：M15 优先指初始保护，未借双向调整改变初始选价规则；原建议冷却没有被改成新增硬限制。
- 对照两份提示词：分析输出方向、保护、阻挡与失效事实，交易员针对实际对象决策；分析不假定账户多空。
- 对照结果表达：全平意图遇到终端部分成交不等于主动分批策略；已受理不冒充成交。合同外字段不靠提示词自行创造。
- 对照未知信息：缺少证据只影响依赖它的动作；不补造结构价、峰值、旧保护值或事件有效状态。

## 尚未验证的部分

上述推演只检查规则是否自洽，不能证明收益、胜率或模型遵循率。当前实际输入是否完整提供保护候选、事件身份及最终收益风险，还需后续用真实输入样本核对；本次没有修改相关程序。没有新增 EA 数值阈值或默认启用配置。
