# 智桥整体设计、逻辑与客户体验复审

审查对象：`dev_vue` / `07862b4c`，.NET 4.8 智桥、MT4/MT5 适配、网页配对入口及安装组装。结论：架构职责基本符合需求，但尚未达到普通客户可独立安装、连接和恢复的交付标准。源码审查与定向复现完成；完整真实终端、交易、升级与兼容验收仍为部分完成。

## 用户截图所示问题

![新增档案的识别失败现场](C:/Users/Administrator/AppData/Local/Temp/codex-clipboard-152244d6-16d4-4201-bd50-8dcaa9d2a828.png)

客户端能够枚举已运行的 MT5 路径，但新建档案的 Python、Worker、服务器地址默认均为空。识别需要先运行 Python Worker，故空路径在探针启动前就被拒绝。使用当前 x86 Core.dll 对空路径调用 `Mt5TerminalProbeProcess.Read`，实际返回 `bridge_discovery_paths_invalid`，没有访问 MT5。

依据：MainForm.cs:294；ProfileEditorForm.cs:122、124、142、164；WindowsTerminalDiscovery.cs:68、115。这不是客户操作错误，也不是“未识别到正在运行的 MT5”。

## 客户流程逐步审查

1. **安装与首次打开：不完整。** 网页当前直接提示“在已安装的软件中粘贴”，没有本页下载/安装引导；客户端运行时依赖未随当前构建完整组装。不能让客户先知道 Python 或寻找脚本。
2. **选择终端：方向正确。** 只枚举已运行终端、不自动登录或改变账号；多个候选必须由客户选择。但列表仅显示 MT5 路径，缺少普通客户易辨认的账号信息，识别前应解释这是尚未读取账户的候选。
3. **识别账户：未完成。** 关键依赖位于长表单下方，按钮可点但必然失败；截图中终端路径字段还需要滚动。依赖应自动就绪，缺失时就地显示具体组件及恢复操作，不能笼统要求检查三类路径。
4. **配对：逻辑部分完整，交互绕。** 临时码、到期、重试草稿有实现；网页和客户端之间仍有地址与操作顺序断点。终端身份应自动只读填入，客户只确认账号并粘贴配对码。
5. **连接结果：缺少共同完成标准。** 网页仅生成配对码，并把连接结果交给软件；配对、服务器连接、终端连接、账户快照和报价就绪必须分开表达。客户端汇总目前是档案数/适配器数，不是需求中的用户连接上限/占用/剩余额度。
6. **更换账户：职责正确但实现需修。** 只更换档案绑定、停止旧路由，不自动改变 MT 登录；需要显式确认目标并保证旧 uncertain 对账不转移。运行配置编辑缺陷见上表。
7. **失败恢复：信息不足。** 不应只显示英文机器码或“检查配置”。每类失败都需回答：哪个账户、哪一层失败、是否正在重试、客户该做什么；机器码放诊断详情。
8. **退出与升级：存在基础保护，尚未完成客户验收。** 本轮前已修复管道关闭崩溃与旧空配置读取；这只证明对应修复，不代表完整关闭/升级可靠。托盘驻留、关闭按钮语义、更新恢复必须有明确产品约定和实机证据。

## 建议保留与调整的设计

保留：轻量原生客户端、每档案隔离 Worker/SQLite/连接、服务端控制权限和额度、精确账户路由、未知结果先对账、客户端不提供策略与交易决策、不启动/关闭/登录 MT 终端。

默认客户流程压缩为三步：

1. 打开软件，自动检查内置组件；选择已登录的 MT4/MT5。MT4 单独引导安装/加载 EA，MT5 自动使用私有运行时。
2. 自动读取并只读展示账号、券商、平台，客户核对；粘贴网页配对码。
3. 显示“配对成功→服务器连接→终端数据就绪”，完成后返回账户卡片。连接失败保留步骤和输入，提供明确重试。

主窗口每张账户卡只突出：账户/券商、终端状态、服务器状态、最新数据时间、连接/断开、更多操作。额度从服务端读取。终端实例ID、Python/Worker路径、WebSocket地址、原始错误码进入诊断或受控开发配置；不能要求普通客户填写。

## 两轮复审与实施顺序

第一轮（需求与职责）：不重建另一套客户端，不往智桥加入会员/风控决策；内置运行时与三步接入是补齐既有需求。高级设置不能成为默认流程前置条件。MT4和MT5入口统一，但适配安装方式分别说明。

第二轮（异常与兼容）：先修合法空值及 uncertain 上下文，再修配置变更/单实例；最后组装运行时和接入交互。保留原配置与账本，不能以删档重配作为修复。未验证运行时不能自动执行；旧账户未决结果不能转移到新账户。变更失败保留上一份可用配置与版本。

验收顺序：离线合同/并发回归→全新用户安装与识别→真实只读 MT4/MT5 配对和数据→断网、终端退出、换号、双开、重启→签名更新与回滚→Windows 7/10/11 和长稳。真实交易另行在用户确认的测试账户中验收。
