## 两轮定向复核

第一轮检查目标与职责：仅实现服务于两份提示词的小型本地工具，未增加 Web 页面、数据库、通用发布平台或交易入口。作者证据与系统反馈、真实工作区与合成示例分开。

第二轮检查兼容和失败路径：使用当前合同正文，候选文件校验后使用；解析和协议失败保留；动作只指向输入中的当前账户对象；旧版不被覆盖；公开断言复核与完整风控执行区分。模块之间按资料、规则、生成、调用、验证职责导入，没有修改生产模块或通过私有运行入口调用服务。

## 尚未验证与当前限制

- 没有作者原始资料和真实项目输入，本次未生成可作为作者策略使用的两份最终提示词。
- 未发送真实模型请求，HTTP 调用为 Mock 验证；模型遵循率、方法还原度、效果与收益均未验证。
- 视频／图片／Excel／PDF 目前只登记，需先提供可靠文本；未实现 ASR、OCR、MT5 采集或完整成交重建。
- 本地验证器不是平台风控副本；公开推理断言也不等于完整项目业务链验收。实际入场价格、预算、保证金、精度和执行权限仍由运行项目检查。
- 曝光记录只跟踪本工具内相同输入，不能自动证明完整统计独立性；规则解释与隐藏未来信息仍需资料复核。
- 不自动发布或回滚正在使用的策略。人工选用哪个候选版本属于后续实际使用步骤。
