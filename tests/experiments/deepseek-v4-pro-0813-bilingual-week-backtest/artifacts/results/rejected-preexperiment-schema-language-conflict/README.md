# Rejected pre-experiment: response-language conflict

These nine successful transport records are retained only as audit evidence and
are excluded from the formal 2x2 summary.  The pre-experiment rendered the
faithfully translated English schema (which still requires narrative values in
Chinese) and then appended a conflicting instruction requiring English values.
That changed semantics and made schema-language effects uninterpretable.

The formal batch instead renders the same Simplified-Chinese response
requirement in the language of each schema specification.  This keeps response
semantics fixed while varying only the strategy prose and schema-description
languages.
