# AI 交易实验室（trade）覆盖规则

- 默认深色，面向长时间盯盘；页面按“当前答案 → 行动 → 证据 → 历史”组织。
- 桌面使用固定顶栏、默认展开的任务侧栏和独立滚动内容区；移动端侧栏进入 Sheet。
- 顶栏在所有页面持续显示 Bridge、自动分析倒计时、交易权限、市场状态和终端时间，并提供就地管理入口。
- 红绿只表示交易方向；Bridge、保存、任务等系统状态使用独立语义色。
- 行情与账户采用 HTTP 一致快照加 WebSocket 增量；更新单个数值，不重挂整个页面或制造闪烁。
- 复杂推理、交易详情和风控证据采用全屏 Dialog/Sheet 渐进披露，不能用拥挤小卡片替代。
