# AURUM V4 设计系统

> 本文件是三端共同的视觉与交互基线。页面专属规则位于 `pages/`，只能收窄或补充本文件，不能绕过无障碍、组件复用和语义色规则。

## 产品方向

- 面向普通外汇交易者：先给结论、当前状态和下一步，再渐进披露专业数据。
- 科技感来自实时、精确、顺滑和可验证，不来自霓虹、扫描线、炫光或装饰性玻璃。
- 三端共享品牌语言，但不共享业务页面：主站是企业与课程官网，交易实验室是任务工作台，后台是高密度运营工具。

## 组件与实现

- 统一使用 Vue 3、TypeScript 严格模式、Tailwind CSS 4 和 `shadcn-vue`（Reka 基座）。
- `frontend/packages/ui` 是唯一通用组件源。已有 shadcn-vue 组件可以满足时，业务代码不得手写第二套按钮、输入框、弹窗、抽屉、菜单、提示或导航。
- 图标统一使用 Lucide；禁止 Emoji 充当操作图标。
- 页面只组合组件和领域模块，组件不得直接请求 API、打开 WebSocket 或持有跨域认证令牌。

## 视觉令牌

- 字体：`Inter, Noto Sans SC, Microsoft YaHei, PingFang SC, sans-serif`；价格、时间、手数等数字使用系统等宽后备并启用等宽数字。
- 间距：4 / 8 / 12 / 16 / 20 / 24 / 32 / 40 / 48 px。
- 圆角：控件 8px，面板 12px，主容器 16px；不使用整页胶囊化。
- 静态结构优先使用背景层级和 1px 边界；阴影只用于菜单、抽屉、弹窗和当前浮层。
- 禁止装饰性渐变、霓虹发光、扫描线、毛玻璃背景和布局位移式 hover。

## 语义色

- 品牌主色默认蓝；用户主题色仅改变品牌与焦点令牌，不改交易和系统状态含义。
- 中文交易语境：上涨/做多为红，下跌/做空为绿。
- 系统正常使用青绿，等待或复核使用琥珀，系统错误与危险操作使用危险红。
- 任何颜色状态必须同时有文字、图标或形状，不能只靠颜色表达。

## 交互与动效

- 主要操作、触摸操作和图标按钮最小点击区域 44×44px。
- hover/focus/展开使用 150–220ms 的透明度、颜色或位移动效；实时数据更新不得闪烁整个容器。
- 所有动画遵守 `prefers-reduced-motion`；路由切换不等待动画完成。
- 加载使用保留布局的 Skeleton；错误说明原因和可执行下一步；空状态说明为什么为空。

## 响应式验收

- 必测宽度：375、768、1024、1440px。
- 移动端不得横向滚动，不得让固定顶栏遮住内容；复杂表格提供行详情而不是压缩到不可读。
- 侧栏桌面默认展开并显示文字；窄屏使用 Sheet，折叠后图标必须水平、垂直居中。
- 一个页面只保留一个主标题和一个主要操作焦点。

## 交付检查

- 组件来源、键盘焦点、对比度、44px 触控、减少动态效果均通过。
- 三端没有互相导入，业务 View 没有直接 `fetch` 或 `WebSocket`。
- 没有假业务数据冒充真实数据；尚未接入的能力使用明确空状态。
- 文案中文优先，内部错误码只在可展开技术详情中出现。
